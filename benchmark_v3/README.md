# EM-benchmark v3 —— 低空环境信号模型与分级评测数据集

> **v3 是什么**：把「低空多源电磁干扰智能分析」做成一套**可控、可评分、可归因**的仿真题目——
> 19 类低空辐射体 + 真实城市射线追踪信道 + 12 件信号测量工具 + 八轴答案与三视角评测。
> 它是**可控仿真**，不是真实采集；真实 SDR 采集属于 v4。
>
> **给谁用**：把模型或 Agent 接上本版的数据与工具，即可在统一答案契约下评测「有没有干扰 / 几个源 /
> 什么体制 / 在哪 / 什么意图」，并定位分数损失来自题目、仪器还是考生。

---

## 1. 与 v2 的关系

| 维度 | v2（冻结版） | v3（本版） |
|---|---|---|
| 场景 | 抽象电磁环境（数学信号） | **低空环境**（空地链路 + 真实城市几何 + 真实辐射体） |
| 干扰池 | 5 种代表性调制 + 简单波形 | **19 类低空辐射体**（含跳频 / 突发包 / 脉冲串 / 扫频等真实时域行为） |
| 信道 | CFO + 阵列导向 + LNA + 阵元失配 + AWGN | + **多径**（RT 射线追踪，逐径时延/增益/离开角）+ **IQ 不平衡** + **相位噪声** + **IMD3 非线性** |
| 噪声 | AWGN | **热噪永开 + 四类前端噪声按站分档**（有色 / 脉冲 / 共模相关 / 相噪） |
| 任务 | 检测 / 分类 / 参数估计 / DOA / 体制识别 | + **辐射体溯源** + **敌我意图** + 分级难度与分站观测 |
| 样本格式 | `.npy (4,1024)` + 三 JSON | **同构**（v2 的工具与评估器可直接消费 v3 样本） |

## 2. 数据基座

### 2.1 评测矩阵

**任务层 T1–T3 × 难度 D1–D4 × 观测条件 S0–S2**。

- **任务层**：T1 感知（源数 / 频偏 / DOA / 定位）→ T2 认知（体制 / 辐射体溯源）→ T3 决策（敌我意图 / 欺骗识别）。
- **难度是"场景包络"而不是 SNR 旋钮**：SNR 由几何与功率推算得到。
- **观测条件只是分站取用**（同一份 IQ，不重采）：S0 = station_a；S1 = a/b/c；S2 = a/b/c/d。
- **评分分母（2026-10-13 起）**：真值里**有源、但该观测档一个都不可见**的样本不计入该档分母（S0 实测 D2 7/100、D3 14/100、D4 12/100——源被城市几何挡住，报 0 即对、不度量能力）；真值**根本没有源**的样本（D1 的设计干净样本）照旧计入——报 0 正是要考的。报告单列 `excluded_zero_visible_n` / `n_total_seen`（`eval_dataset.sample_counts_for_slevel()`，证据 `evidence/_s0_visibility.txt`）。

### 2.2 四档难度

| 级 | 名字 | 目标侧 | 干扰侧 | 信道 / 观测 | 相对上一级新增 |
|---|---|---|---|---|---|
| D1 | 看得见 | 10–20 dBm，视距 | 0 / 1 个简单干扰（单音或窄带噪声），与目标频域分离 ≥50 kHz | 自由空间 + 仅热噪；站环绕目标 | 基线：干扰躺在频谱空地上 |
| D2 | 挤得慌 | 10–20 dBm，视距 | 2 个共存辐射体（蓝牙 / WiFi / 微波炉 / Zigbee / DECT） | 城市 RT（多径 / 遮挡）；与目标共道深重叠 | **频谱重叠**：必须靠角度与波形分辨 |
| D3 | 有人捣乱 | **0–10 dBm + 楼后 NLoS** | 1–2 个恶意压制（扫频 / 噪声 / 单音）+ 50% 混一个共存源 | 城市 RT；站网固定环绕 AOI，目标漫游进入 | **目标弱 + 恶意意图**（T3 成为新轴） |
| D4 | 极限藏匿 | 0–10 dBm + 楼后 + **机动多普勒** | **GNSS 欺骗** + 恶意压制 + 共存源 | 城市 RT；接收机开 IMD3 非线性 + 阵元相关噪声 | **欺骗与非线性**：出现"长得像合法信号"的源 |

### 2.3 数据集（各 50 样本）

| 目录 | 难度 | 传播 | 干扰 | 目标 SNR |
|---|---|---|---|---|
| `dataset_d1/` | D1 | 视距 | 50% 无 / 50% 单音或窄带噪声（Hz 域与目标分离 ≥50 kHz） | 12–38 dB |
| `dataset_d2/` | D2 | 城市 RT | 2 个共存辐射体（共道重叠 + 可辨识性约束） | 15–41 dB |
| `dataset_d3/` | D3 | 城市 RT + NLoS | 1–2 恶意压制 + 50% 共存 | 1–34 dB |
| `dataset_d4/` | D4 | 城市 RT + NLoS | GNSS 欺骗 + 恶意压制 + 非线性 / 相关噪声 / 多普勒 | 1–34 dB |

**统一采集口径**：`fs = 4 MHz`、载频 `2.4 GHz`、**8 元阵 × 40000 点 = 10 ms**、4 个监测站。
设备布点经楼宇占用栅格拒绝采样（不在楼内、离墙 ≥5 m）；D3/D4 的目标置于楼后，使低 SNR 有物理出处；
每站 LoS/NLoS 与逐源可见性都进真值。

### 2.5 辐射体库（19 类）

| 分组 | 辐射体 |
|---|---|
| 通信 | `Bluetooth_FHSS`、`WiFi_burst`、`LTE_QPSK`、`DECT`、`Zigbee` |
| 无人机 | `UAV_video_OFDM`（图传下行）、`UAV_RC_hopping`（遥控上行） |
| 雷达 / 导航 | `Radar_pulsed_LFM`、`GPS_DSSS`、`GNSS_jam`、`GNSS_spoof`、`TV_broadcast` |
| 对抗干扰 | `Chirp_jam`、`Noise_jam`、`Tone_jam` |
| 工业 / 城市脉冲 | `Welder`、`VFD_noise`、`Corona`、`Microwave` |

意图标注（T3 答案轴）：`malicious`（明确对抗）/ `incidental`（无意共存）/ `benign`（正常合法信号）。
`is_jamming = True` 的对抗源：`GNSS_jam`、`GNSS_spoof`、`Chirp_jam`、`Noise_jam`、`Tone_jam`。

### 2.6 数据质量约束（QA 三约束）

生成期强制三条，不合格布点重抽、不凑数：

1. **每个干扰 ≥3 站 LoS 可见**（保证题目"收得到"）；
2. **同频源对空域可分** `|Δu| ≥ 2/M`；
3. **不合格布点重抽**，不允许用不可解样本充数。

效果（D3 / D4）：干扰「≥3 站可见」占比 **17.6% → 92.6%**、**16.1% → 96.0%**；
"什么都不报也能拿分"的漏洞随之收窄（报 0 即正确的样本 58%/48% → 30%/6%）。

### 2.7 前端噪声（按站分档）

热噪在四档**永开**；其余旋钮按**每台接收机独立抽签**（同一立场站间不共享），菜单写在
`index.json.noise_menus`：

| 档 | 配方 |
|---|---|
| D1 | 热噪 100%（保留为归因参照系） |
| D2 | 热噪 60% / 有色 40% |
| D3 | 热噪 40% / 有色 30% / 脉冲 30% |
| D4 | 热噪 20% / 有色 20% / 脉冲 30% / 共模相关 30% |

解析抬升与信道重放实测吻合在 **0.01–0.03 dB**（`noise_profiles.py` 的解析式 vs 重放实测）。

### 2.8 公开层：受害者层证据与合作链路先验

按场景规范 §7，Agent 可见**机理与行为证据**、但**不可见** GT 的 `aimed / victim` 字段：

- `interference_events`（写入 `public/observations.json`）：`event_id / source_id / mechanism / impact_class`，
  其中 `mechanism ∈ {jam, spoof}` 是意图轴的直接行为证据，但**只是部分视图**（不是源普查，也不含计数）；
- `cooperative_sources`：合作目标（型号 + 名义带宽）与逐站链路质量遥测，属合法公开先验。

D3 有 48 条事件（48/50 样本）、D4 有 100 条（50/50 样本，jam 50 + spoof 50），D1/D2 无事件。

## 3. 仿真链路

```text
19 类辐射体波形（simulation/em_signal_simulator_v3/emitters.py，统一软带限）
      │
      ├─► 解析信道（channel_env.py：多径 / IQ 不平衡 / 相噪 / IMD3）——离线生成器用
      │
      └─► 物理平台（城市低空电磁信号仿真平台/，Sionna RT + 真实城市 LoD1 几何）
              │  适配器 adapters/cityrf_source.py：把 v3 辐射体当"信号源"送进平台，
              │  复用平台的信道求解 / 卷积 / 接收机 / 导出（**不改平台源码**）
              ▼
      接收机（前端噪声开关 + 带通滤波 + 调谐）
              ▼
      capture/public/iq_station_{a..d}.npy  +  observations.json（Agent 可见）
      capture/private/…                     +  truth.json / d1_truth.json（答案键）
```

- 平台运行需 **WSL + LLVM 后端**（`LD_LIBRARY_PATH=/usr/lib/llvm-17/lib`），RT 端点须在室外且天顶可见。
- 信道是**时不变冻结链路**：改噪声档位 / 采窗长度时可用 `adapters/regen_noise.py` 直接重放接收链
  （纯 numpy，秒级/样本，不重跑 RT），且与原管线逐位等价。

## 4. 仪器层：12 件测量工具

工具集中在 `adapters/capture_tools.py`，只返回**测量值与候选证据**，不下最终结论：

| 工具 | 作用 | 主要服务 |
|---|---|---|
| `analyze_spectrum_station` | 单站频谱 / 占用 | T1 感知 |
| `estimate_band_occupancy_by_correlation` | 残差峰判据（局部底 + 空间相干门控） | T1 检测 |
| `estimate_num_sources_station` | 源数估计 | T1 检测 |
| `estimate_sources_by_spatial_clustering` | 多站聚类定带与分组 | T1 检测 / T2 |
| `estimate_doa_station` | 来向估计（单站 ULA） | T1 空间 |
| `estimate_position` | 多站交会定位 | T1 空间 |
| `extract_source_waveforms` | 波束成形提取单源波形 | T2 |
| `estimate_modulation_features_station` | 调制特征（瞬时频率/幅度/谱形） | T2 体制 |
| `classify_extracted_waveform` | 波形 → 辐射体（19 类 CNN 分类器） | T2 溯源 |
| `detect_time_domain_station` | 时域能量 / 占空 | T2 / T3 |
| `analyze_time_frequency_station` | 占空比 / 突发数 / 跳频信道数 / 扫频斜率 | T2 / T3（跳频与共存体判别） |
| `list_radiator_catalog` | 辐射体目录（合法先验） | 辅助 |

**关键设计（本层踩过坑的地方）**：

- **残差提取**：用与合作目标同 seed 的"无干扰"接收链构造参考并直减；参考侧只关加性噪声项，
  保留相位噪声与 IMD3（否则目标残影留在残差里）。
- **峰判据**：局部中位底（300 kHz 滑窗）+ **窄窗空间相干门控** `λ1/Σλ(±3 kHz) ≥ 0.6`。
  真源 ≈1.0，参考失配能量 ≈0.13（8 元阵白噪理论 1/8）——判据从"能量多大"换成"跨阵元是否相干"。
  **窗宽校正（2026-10-12）**：±20 kHz 会把窗内 ~3200 个 bin 一起做协方差，纯音只占 1~8 bin，
  相干能量被非相干失配底稀释（真源 coh 掉到 0.39 而被滤掉）；收到 ±3 kHz 后 D1 真源覆盖
  由 80.4% 回到 92.2%（旧代 92.6%→100%），干净样本虚警恒 0（证据 `evidence/_sweep_cohwin_*.txt`、
  `_d1_gate_*_coh3k.txt`）。判据阈值 0.6 未动——这是量测窗的度量修正，不是放宽门限。
- **两套峰清单解耦**：给 Agent 的 `residual_peaks`（门控窄带）与仅供内部聚类定带的
  `residual_peaks_legacy`（旧宽带，下游"同组"判据依赖 `band_hz` 宽度）**必须分开**，
  对外工具会剥掉内部字段。
- **定带判据实验（2026-10-12，默认关）**：`DSH_PEAK_BANDS_B=1` 把聚类侧的"共道支持带"换成
  相干支撑连通域（去固定 10 kHz 网格、去最小长度、允许跨相干谷合并，`_residual_bands_support`）。
  带级确实变好（D1 覆盖 90.2%→98.0%、多余带 31→0；D2 覆盖 37.1%→67.7%、多余带 220→82），
  但**端到端没有收益、反而更差**：受控台同一认领对上 `B_base_mk` 0.262/0.375 < `a7_base_mk`
  0.279/0.438；D2 全链路 tool-view 召回 0.709→0.744，但假簇 0.479→0.504、条件分类 0.246→0.172、
  端到端 0.174→0.128。⇒ 瓶颈不在"带边怎么切"，而在候选**位置/混合**（真位置+掩蔽
  `b7_base_mk` 0.516 vs 现行 0.438，旧档）。证据 `evidence/_diag_d2_off_B_{new,old}50.txt`、
  `evidence/_gate_d2_quota100_B{off,on}.txt`、`evidence/_stepedges_*.txt`。
- **鲁棒回退**：三站交会失败时按 trio（定带）→ trio（整通带）→ duo（2D 方位线）回退，覆盖端射区。

## 5. 评测口径

### 5.1 答案轴与容差（预注册，不随数据集变化）

| 题目 | 答案形式 | 判定口径 | 任务层 |
|---|---|---|---|
| 有没有干扰 / 几个源 | 干扰计数 | **计数完全一致**记 `detection_hit`；相差 ≤1 另记 `within1` | T1 |
| 什么体制 / 什么辐射体 | 19 类标签 | 精确命中（D1 为 tone/noise 体制级） | T2 |
| 载频 | `freq_offset_hz` | 归一化 `|Δ| ≤ 0.02`（= ±40 kHz @4 MHz） | T1 |
| 来向 | `doa_deg` | `|Δ| ≤ 10°`（仅 S0 单站视角） | T1 |
| 位置 | `position_m` | 门限 **50 m**（仅 S1/S2 多站） | T1 |
| 意图 | `malicious / incidental / benign` | 精确命中（贪心匹配） | T3 |
| 欺骗 | `is_spoof` | 真值 = `kind == "GNSS_spoof"`（仅 D4 有正分母） | T3 |
| 机理 | `mechanism` | `co_channel` / `adjacent` / `pulse` / `spoof` 精确命中；**只在配对成功的对上计分** | T2 |

可检测性门限：该站 INR ≥ 3 dB 才计入真值分母。

### 5.2 三种评测视角（必须分开报）

| 视角 | 含义 | 作用 |
|---|---|---|
| `clean` | 无干扰样本上跑 19 类分类器 | 测仪器"会不会看花眼"（虚警） |
| `gt_slice` | 用真值替换考生、只留仪器链路 | 测**仪器上限**（题目最多能给到多少） |
| `tool_view` | 仪器候选口径（召回 / 假簇 / 条件分类 / 可解子集 / e2e） | 测仪器把题目变成"可判分"的能力 |

预注册门限：clean ≥ 0.85；GT 切片与 tool-view 的条件命中 ≥ 0.50。
只有三段都过，端到端的分数才可以归因到模型能力。

### 5.3 答案契约与拒答

Agent 每样本输出一个 JSON：`{"interferers": [{"freq_offset_hz", "kind", "mechanism", "intent",
"is_spoof", "doa_deg", "position_m"}]}`——**计数由条目数派生**（不再要求模型报数）。
空列表且工具确实没给出候选 = 合法答案"无干扰"；空列表但工具已给出候选 = 拒答（`abstained=true`，
评测端另报 `detection_hit_excl_abstain`）。注册口径 `detection_hit` 仍含拒答。
`mechanism` 取四值 `co_channel / adjacent / pulse / spoof`（用户 2026-10-11 拍板；另有
`blocking / imd / harmonic` 在当前几何下零正样本、不参评）。真值侧由 `kind + 频偏 + 带宽` 现场派生
（`adapters/mechanism.py`），不要求回写数据集。设计、口径与解读纪律见
`docs/干扰机理轴_设计与口径.md`。

## 6. 当前结果

### 6.1 四档 Agent 基线（配额数据各 100 样本、注册口径评前 50；2026-10-12）

| 档 | 检测计数 | 相差≤1 | 体制 / 溯源 | 载频 | 空间轴 | 意图 | 欺骗虚警 |

### 6.2 机理轴（配额四档，2026-10-12，注册臂评前 50）

机理**只在配对成功的对上**计分，所以分母小于 GT 干扰总数（关联本身是更难的一轴）。

| 档 | 配对数 | 机理命中 | 同分母常数基线（多数类） | 差值 |
|---|---|---|---|---|
| **D1×S0** | 24 | 0.583 | **1.000**（真值单类 adjacent，无信息） | −41.7 pp |
| **D2×S2** | 79 | 0.468 | 0.456（co_channel） | +1.2 pp |
| **D3×S2** | 86 | 0.593 | 0.477（co_channel） | +11.6 pp |
| **D4×S2** | 106 | 0.519 | 0.340（co_channel） | +17.9 pp |

真值侧机理现在是**三到四类**（产物配额：D2 co 45%/pulse 30%/adjacent 25%，D3 co 50%/adjacent 30%/pulse 20%，
D4 spoof 30%/co 30%/adjacent 20%/pulse 20%）；旧一代只有 D1 单类、D2 两类的极端集中。

**读法（必须带上）**：机理是 `kind + 频偏 + 带宽` 的**派生量**。在同分母常数基线下，D2 的增益只有 +1.2 pp，
D3/D4 为 +11.6 / +17.9 pp（比旧一代的 +1.1~+5.2 pp 改善但仍远低于体制/载频/空间三轴）。
该轴**仍只作诊断列**：横向比较看同分母基线差值，不看单个 accuracy。
（同批仪器的 tool-view 条件分类只有 0.246~0.429，体制轴的 CNN 误分类会直接映到机理轴上。）
### 6.3 仪器 gate（`cd adapters/rad_cls && python oracle16.py`；D2–D4 走分类器三视角，D1 走相干门控口径）

| 档（覆盖样本） | clean | GT 切片 | tool-view 召回 | tool-view 假簇 | tool-view 条件 | 判定 |
|---|---|---|---|---|---|---|
| **D2×S2**（100 样本；tool-view 前50） | 0.877 [1000/1140] PASS | 0.472 [75/159] | 0.709 [61/86] | 0.479 [56/117] | 0.246 [15/61] | **FAIL** |
| **D3×S2**（100 样本；tool-view 前50） | 0.877 [1000/1140] PASS | 0.551 [87/158] PASS | 0.372 [35/94] | 0.602 [53/88] | 0.400 [14/35] | **FAIL** |
| **D4×S2**（100 样本；tool-view 前50） | 0.877 [1000/1140] PASS | 0.378 [88/233] FAIL | 0.206 [28/136] | 0.736 [78/106] | 0.429 [12/28] | **FAIL** |
| **D1×S0**（门控口径，100 样本） | 虚警 0.000 [0/49] | 覆盖 0.922 [47/51] | 频率命中 0.902 [46/51] | — | — | 通过 |

**读法**：clean 四档都是 0.877 → 仪器在无干扰时不会看花眼；GT 切片只有 D3 过线（0.551），
D2 0.472 / D4 0.378 说明“给完美候选”时分类器自己就丢分（D2 的主要误分类是 `WiFi_burst` 0/24、`Zigbee` 0/28）。
tool-view 三档全 FAIL，且**召回与假簇同时变差随难度单调**（召回 0.709→0.372→0.206，假簇 0.479→0.602→0.736）——
即仪器**把题目变成可判分证据**的能力是当前公开承认的短板。
D1 是单站 + legacy `tone`/`noise`（不在 19 类分类器标签内），只能用相干门控口径量：干净虚警 0、覆盖 0.922、频率命中 0.902。
证据：`evidence/_gate_d{2,3,4}_quota100_coh3k.txt`、`evidence/_d1_gate_regen_v2_coh3k.txt`。

### 6.4 已知局限

- **D2–D4 的空间精度**：共道带（中位 851 kHz）在频率上不把同频源分流，叠加城市多径，
  定位误差中位 211–620 m，远大于 50 m 门限；这属仪器能力，不代表题目不可解。
- **D1 的 DOA 0.28**：单站线阵前后瓣镜像的物理结果（单站上限约 0.5），不是模型问题。
- **体制轴瓶颈**：主要来自 tone/noise 混淆与同频共存体的频谱不分离。
- **CNN 溯源分类器**为自训模型（19 类，val_acc 0.882），构成 GT 切片口径的一部分误差。

### 6.5 已证伪并关闭的路线（后人不必重试）

峰独占、duo 交会、频偏精测、位置精化、双字段门限、deflation 硬门限当去假主力、
MUSIC 阈值放宽、occupancy floor 改分位数、50 kHz 带去重、**同源并合**（多余候选不是被拆开的同一个源）、
**逐频窗窄带特征值秩枚举**（无源窗 94.9% 仍报 ≥1 个超阈特征值：RT 多径让单源秩 2–3）、
以及"在 prompt 里禁止模型输出负哨兵"（实测反噬）。

## 7. 怎么用

```powershell
# 依赖：numpy scipy matplotlib pillow openai tqdm（平台另需 pydantic；RT 需 WSL）

cd benchmark_v3\adapters

# 评测（GT 回放应全 1.0，用于验证评分管道）
python -u eval_dataset.py ../dataset_d1

# 评测某个答案目录（Agent 输出）
python -u eval_dataset.py ../dataset_d2 --answers ../dataset_d2/answers_S2_agent_fix2 --out ../_eval.json

# 数据集结构审计
python -u audit_dataset.py ../dataset_d3 --d2

# 仪器 gate（三视角）
cd rad_cls; python -u oracle16.py

# Agent 考生（在仓库根启动；Key 在 run_capture_agent.ps1，已 gitignore）
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_capture_agent.ps1 `
  -Dataset dataset_d2 -SLevel S2 -Answers ../dataset_d2/answers_S2_agent_xxx
```
