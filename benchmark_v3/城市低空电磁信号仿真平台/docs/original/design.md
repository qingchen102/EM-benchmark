# 静态城市多点仿真：已批准架构

2026-09-14 更新：用户要求水平8＋垂直8的16通道十字阵，替代下文初版ULA默认。空间记录包含阵列中心、姿态、旋转矩阵、阵面法向、逐阵元局部与绝对坐标；详见 cross-arrays.md。矩形面阵和旧线阵仍支持。

用户于 2026-09-14 批准实现。范围：静态几何、多目标、多干扰、多接收站，共同时间起点的 50 ms IQ；无流式系统、移动、多普勒演化或协议栈。

采用组件组合：Scenario → Waveform/TxChain → PropagationBackend → ChannelApplicator → RxChain → Observation/Truth。单发射端口，接收站为同步校准 ULA；首版同频段、共同内部采样率，允许接收中心调谐，严格检查抗混叠范围。

功率约定：天线端口有源期间平均功率，单位 W 的复包络平方；理想各向同性单极化天线增益由信道施加。组合成分按功率权重，门控后不重新归一化。发射带宽为占用配置，不宣称符合专用无人机协议。

信道保留绝对延迟和损耗，静态逐路径复系数含天线响应。提供自由空间、指定抽头、Sionna RT 后端；不静默回退。时域施加分数延迟时使用带限 sinc FIR 和前后保护样点，不循环卷积。

接收机先叠加再非线性，默认理想线性、固定增益、等效输入热噪声；可选软限幅，明确为代理模型。数据输出 complex64 [channel,sample]。物理源、传播路径、接收任务分别保存真值，模型侧只读取公开 observation。

RT 使用独立 WSL Python 环境，版本锁定 2.1.0；CPU DSP 亦可在 Windows 执行。保留空间方向坐标约定、路径与配置哈希、版本、测量和验证报告。

本次实现仿真底座、公开数据接口和既有 Agent 的离线兼容验证；不改写既有单站推理核心，不将多站协同推理宣称为已完成。
