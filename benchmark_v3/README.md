## 3. 设计原则

1. **复用已验证的信号原语**：新增环境层与时域行为层，基带/信道基础效应/评分接口全部复用已验证实现；
2. **可组合**：信道效应是独立函数，参数暴露为关键词参数，便于消融（"多径贡献多少难度"可以用开关量化）；
3. **信息隔离不变**：辐射体标签仅入 ground_truth/metadata，observations 不含；
4. **每一步过闸**：预注册门槛 + 离线验收流程覆盖每个新效应与新数据集。

---

## 4. 设计依据（与申报书对齐）

申报书对多源干扰智能分析场景的要求：提取**频率偏移、带宽占用、调制方式、空间传播路径**，建立**同频/邻道/阻塞/脉冲**典型干扰特征库 + 电磁指纹库 + 干扰源高精度定位；干扰来源明确含"**同频设备、非法信号源、环境反射**"。v3 的任务轴与辐射体池即按此口径设计：

- 频偏/带宽/DOA → T1 感知任务（v2 已有）；
- 调制/辐射体溯源 → T2 认知任务（v3 新增答案轴）；
- 敌我意图（对应"非法信号源 vs 环境反射"）→ T3 决策任务（v3 新增答案轴）；
- 环境反射/多径 → 信道层（解析多径 + Sionna RT 城市场景）。

已定设计口径：辐射体清单维持 16 种；溯源任务按"体制 → 调制 → 辐射体"细分，敌我意图作为 GT 答案轴；信道参数以申报书定性描述（路径损耗、多径、环境反射）为依据取工程默认，待实测校准；**带宽语义 = 整窗总跨度（OBW99，实测）**，与频谱工具可测口径对齐。

分工：v3 = 考卷 + 答案轴 + 阅卷；物理平台 = 真实空间信道 / 环境。两者互补不替代，真实数据（v4）接入时仅换数据源。

## 6. 分级数据集与评分

评测框架三维：**任务 T1–T3 × 难度 D1–D4 × 观测条件 S0–S2**。

- **任务层**：T1 感知（源数/频偏/带宽/DOA）→ T2 认知（体制/辐射体溯源/干扰类别）→ T3 决策（敌我意图/威胁评估）。
- **难度**（定义为场景包络，SNR 由几何+功率推算、不是旋钮）——四级递进，每一级在上二级上**新增**一组物理困难：

  | 级 | 名字 | 目标侧 | 干扰侧 | 信道 / 观测 | 相对上一级新增的困难 |
  |---|---|---|---|---|---|
  | D1 | 看得见 | 10–20 dBm，视距 | 0/1 个简单干扰（单音/窄带噪声），频率上**与目标分离 ≥50 kHz** | 自由空间+仅热噪声；监测站环绕目标；**采集 4 MHz** | 基线：干扰在频谱空地上、一眼可见 |
  | D2 | 挤得慌 | 10–20 dBm，视距 | 2 个**共存辐射体**（蓝牙/WiFi/微波炉/Zigbee/DECT，无害），频率上**互相与目标重叠** | 杭州 RT（真实多径/遮挡）+热噪声；监测站环绕目标；采集 2 MHz | **频谱重叠**：目标宽 + 干扰拥挤成一片，源的分离从"看频谱"退回"需角度/波形分辨" |
  | D3 | 有人捣乱 | **0–10 dBm 低功率 + 放楼后 NLoS**（物理低 SNR） | 1–2 个**恶意压制**（Chirp/Noise/Tone jam）+ 50% 混一个共存源 | 杭州 RT；监测网**固定环绕 AOI**、目标漫游进入 | **目标弱到难测 + 出现恶意意图**：目标 SNR 大幅下降，且干扰从"无害共存"变为"蓄意对抗"（T3 敌我意图成为新答案轴） |
  | D4 | 极限藏匿 | 0–10 dBm + 楼后 + **机动多普勒**（目标带速度） | 含 **GNSS 欺骗**（合法结构、错误参数）+ 恶意压制 + 共存源 | 杭州 RT；接收机开 **IMD3 非线性 + 阵元相关噪声** | **欺骗与非线性**：出现"长得像合法信号"的欺骗源；接收链引入互调产物与相关噪声，干扰源更难分离 |

- **观测条件**：S0 单站 / S1 三站 / S2 四站——同一采集分站评分，得"多站信息增益曲线"。

### 噪声档位（2026-10-08/09 夜大修：改成「配方菜单 + 按站抽签」）

接收机噪声不再是四档统一的“热噪声”，而是按**物理真实性**分档。档位表 = `benchmark_v3/adapters/noise_profiles.py`（唯一真实来源：刻度常数 + 菜单 + 抽签规则），落地工具 = `benchmark_v3/adapters/regen_noise.py`（frozen-channel 重放）。

| 数据集 | 配方菜单（10 槽抽签权重） | 实测抬底 | 备注 |
|---|---|---|---|
| `dataset_d1/` | thermal 10 | ±0.05 dB | **保持干净**——唯一被证明“能精准测能力”的档（D1/S0 detection 0.083→1.00、虚警 0），留作参照系；字段集必须为空 |
| `dataset_d2/` | thermal 6 / colored 4 | colored **+1.45 dB** | colored = −8 dB/200 kHz（刻度按实测抬底反推） |
| `dataset_d3/` | thermal 4 / colored 3 / impulse 3 | colored **+2.54** / impulse **+1.18** | colored −5 dB；impulse 200 Hz / 25 dB / 5 µs（duty 1e-3，价值在时域结构） |
| `dataset_d4/` | thermal 2 / colored 2 / impulse 3 / correlated 3 | colored **+2.53** / impulse **+1.20** / correlated **+0.00** | 共模 ρ=0.05：参考侧 n0=0 时该支路被跳过，故它的伤害是**真实信号通路**效应，取小 |

**抽签规则**（`noise_profiles.plan_sample`，确定性、不需要随机种子）：10 个槽位按权重等间距撒点；站间步长 7（与 10 互素）→ 同一样本内 4 站取 4 个**不同**槽；样本间步长 3（互素）→ 每个站位置在 50 样本上**遍历 10 个槽各 5 次**（配方占比 == 菜单权重），且各样本的配方构成不同（不是一个构成复制 50 遍）。**为什么按站而不是按样本**：一个样本里的 4 个站就是 4 台不同位置的接收机；按样本随机会让 station_a 系统性偏干净，直接污染 S0→S1→S2 信息增益曲线。落地审计 `_check_noise_landed.py` 全绿（逐样本配方比对、实测底 vs 解析抬升、派生字段），**四站位置的配方分布逐站完全相同**。

**平台噪声机制审计（源码级，`benchmark_v3/城市低空电磁信号仿真平台/src/cityrf/receiver.py`）**——三个坑，都会让档位刻度系统性偏掉：
1. `_colored()` 把有色噪声**归一到时域单位平均功率**（不是谱密度）：`colored_noise_db` 的语义是“有色分量总功率 / 热噪总功率”，而它集中在 ±100 kHz、热噪摊在 ±2 MHz → **0 dB 就已把带内底抬 +5.45 dB**（实测 `rise ≈ 10·log10(1 + 2.47·10^(db/10))`，斜率约 0.87 dB/dB）。**不是 bug，但语义必须写清楚**，否则“0 dB”会被当成“无关痛痒”。
2. `phase_noise_deg` 是**每个采样点**的相位步长 σ（`exp(1j·cumsum(step))` 随机游走），不是总相位：0.01° → 10 ms 内积分相噪 2° RMS（合理）；1.0° → 200° RMS、瞬时频偏随机游走 ±MHz，**等于把本振做坏 100 倍**。
3. **colored / impulse / phase 三个开关不受 `noise_enabled` 总开关管辖** → 造“无噪声参考”时只关总开关会漏掉三项（`_build_target_reference` 原先正是如此）。已修为**只关加性四项、保留 phase 与 IMD3**：数据与参考走同一台接收机、同一时刻，相位误差是**共享的乘性项**，关掉反而在残差里留下目标残影。
