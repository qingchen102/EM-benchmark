# 独立平台与 Web 工作台

目标：将现有静态城市仿真从 Agent 中独立复制；不修改原项目。共享 Scenario 配置，接入本地 Web API、真实慕尼黑网格、2D/3D 场景编辑、波形与接收机配置、异步仿真、结果谱图和产物下载。

实现：Python FastAPI + 独立仿真子进程；前端原生 ES modules + 本地 Three.js。基础 DSP 使用当前 Python，Windows 下 RT 可调用已有 WSL 环境。运行时 PYTHONPATH 指向本目录，不能意外导入原 Agent 版本。

范围：保留 50 ms 静态仿真、单端口发射、16 阵元上限、同规格 RT 阵列等真实约束；不将地图显示范围当作 RT 场景裁剪。完整网格为 Sionna Munich 的导出数据。布局连线不是反射路径。

交付与验证：原始文件 SHA256 清单；仿真测试；API 非法输入和异步运行测试；基础与真实 RT 运行；浏览器验证配置、地图切换与结果视图。
