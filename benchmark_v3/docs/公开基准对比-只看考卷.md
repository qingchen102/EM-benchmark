# 公开基准对比（只看「考卷」）

> **这份文档回答什么**：把"数据规模"这一层全部剥掉，只看**它是不是一份能考的卷子**——有没有题面、有没有答案键、有没有成文判分、有没有被真跑过。在这个筛子下，`RFUAV`、`TEXBAT`、`LoRaIQ`、`S-ICDF` 这类"原料库"会整体出局，剩下的对手和 `公开同类数据集维度对比.md` 里的名单**不是同一批**。
>
> **三份文档的分工**
> - `公开同类数据集维度对比.md` —— **数据视角**：和公开 IQ 数据集比规模、比真值轴、比场景。
> - **本文** —— **考卷视角**：和公开基准/竞赛/评测协议比题目、比判分、比信息隔离、比模型横评。
> - `公开仿真平台与信号模型对比.md` —— **仿真平台视角**：和 Sionna RT / DeepMIMO / QuaDRiGa / GNU Radio 这一层比，我们的数据是"过完仿真平台"之后的产物。
>
> 对象：本仓库 `benchmark_v3`（EM-benchmark v3）。全部我方数字来自仓库实测，出处逐条给出。

---

## 0. 为什么必须单独做一遍"只看考卷"

在数据视角下我们会被规模压死：RFUAV 1.3 TB、LoRaIQ 71 GB、南极 GNSS 站 111.7 GB，我们是 4.44 GB，差 1–3 个数量级，这个差距是真的、也没有辩解空间。

但**规模不是考卷的指标**。一份考卷的价值在于：题目边界清楚、答案键独立、判分可复现、别人能拿同一个分数来对话。RadioML 2018.01a 有 255 万条 I/Q 样本、比我们大两个数量级，但它不是考卷——它只有标签，没有题面、没有答题契约、没有成文容差，任何人可以自己切一份子集报一个数字（连 `classes.txt` / `classes-fixed.txt` 的类序都不一致，切法不同分数就不可比）。

所以本文的结论会和数据视角**不一样**，而且是补强而不是重复。

## 1. 入榜标准（四条，缺一不入）

| 代号 | 标准 | 判据 |
|---|---|---|
| **B1** | **任务与答题契约** | 有明确的输入（题面/证据）、明确的输出格式、明确的单题边界。只有"给数据 + 一个标签"不算。 |
| **B2** | **独立真值 / 答案键** | 真值不由被测系统产生，且**不写在题面里**（可以在公开数据集里，但必须与题面分离）。 |
| **B3** | **成文判分协议** | 指标、容差、是否使用 LLM 裁判，全部有文字规定；能据文档复算出同样分数。 |
| **B4** | **公开可复现的评测结果** | 至少有一个被评测系统（模型/Agent/求解器）的分数可被第三方复现。 |

**两条边界规则**（避免把苹果和橘子混进表）：

1. **纯数据集不入榜**——哪怕它有官方 train/test 划分。判据：*它有没有向被测系统提问？* RadioML、WiSig、ORACLE、RFUAV、DroneDetect、DroneRFa、LoRaIQ、TEXBAT、Jammertest 2025、S-ICDF、DeepSense 6G、WASD、Colosseum 原始场景全部出局。
2. **纯工具/库不入榜**——Sionna RT、GNU Radio、MATLAB Toolbox、QuaDRiGa、DeepMIMO、ns-3 出局（它们进第三份文档）。
3. **同一篇工作可能只入一半**——例如 MERLIN：入榜的是它的 **EM-Bench**（4,200 道 QA）；它的 **EM-134K**（134,107 条指令样本）是训练/指令数据，不入榜。同理 EMRB 入榜的是"题 + verifier"，不是它的 `.npy`。

### 2.3 与 UAVBench 的关系：同域，但正交

**它是什么**：Ferrag / Lakas / Debbah（UAEU + Khalifa University），arXiv **2511.11252**（2025-11-14，CC BY 4.0；全文 <https://arxiv.org/html/2511.11252>），IEEE OJVT 正式发表，代码与数据 <https://github.com/maferrag/UAVBench> 。主体是两份各 50,000 条的数据：**UAVBench**（分类学引导的 LLM 生成无人机飞行场景 JSON，含风廓线、能见度、`gnss_multipath`、`gnss_jam_dbm`、`em_interference`、地理围栏、故障元组、通信丢包窗口）与 **UAVBench_MCQ**（50,000 道选择题，覆盖十种推理风格：气动与物理 / 导航与路径规划 / 政策与合规 / 环境感知 / 多机协同 / 信息物理安全 / 能量管理 / 伦理决策 / 系统比较 / 混合推理）。多级校验（schema + 物理/几何一致性 + 风险打分）产出 `label.risk_level` / `risk_category` / `factors`（如 `GNSSMultipath`、`GPSJamming`）。已跑 **32 个 SOTA LLM**（含 GPT-5、ChatGPT 4o、Gemini 2.5 Flash、DeepSeek V3、Qwen3 235B、ERNIE 4.5 300B），指标为 Accuracy / Mean / Std / **Balanced Style Score**；结论是感知与政策推理表现强、伦理感知与资源受限决策持续薄弱。

| 维度 | UAVBench | 我们 v3 |
|---|---|---|
| 考什么 | 决策 / 规划 / 伦理 / 资源取舍 | 检测 / 识别 / 定位 / 意图 |
| 输入 | 自然语言任务 + 场景 JSON | **4 站 × 8 阵元 × 40000 点原始 IQ** |
| 答案形态 | 七选一字母 | 结构化条目（频偏 / 体制 / DOA / 位置 / 意图 / 欺骗） |
| 判分 | Accuracy / BSS | 7 轴 + 预注册容差（±2% 频率、10° DOA、50 m 位置）+ INR ≥ 3 dB 可检测性门限 |
| 题量 | 50,000 场景 + 50,000 MCQ | 200 样本（4 档 × 50），4.44 GB |
| 生成方式 | 分类学引导的 **LLM 生成** + 多级校验 | **数值仿真**：19 类波形 + Sionna 射线追踪 + 接收机前端损伤 |
| 电磁干扰的角色 | **场景 JSON 里的一个字段 + 风险标签** | **被分析的对象本身** |
| 工具层 | ✘ 纯问答 | ✔ 12 件仪器 + 三视角分层 |
| 真值粒度 | 场景级标签 | 逐源逐站（功率 / 方位 / 位置 / 可见性） |
| 许可 | ✔ CC BY 4.0 + 正式论文 | ✘ 仓库无 LICENSE、无预印本 |

**最关键的一条**：它的电磁干扰长这样——`"gnss_multipath": true`、`"gnss_jam_dbm": -110`、`"em_interference": true`，外加风险因子 `GPSJamming`。**这些是 LLM 写进 JSON 的数字和标签，背后没有波形、没有信道、没有接收机。** 所以它能测"LLM 知不知道 GPS 干扰会让定位退化"，**测不了**"能不能从 IQ 里看出 GNSS 欺骗"。它把电磁干扰当作**场景描述里的一个名词**；我们把它当作**要被解出来的答案**。

**它比我们强的地方（要认）**：① 有正式论文与明确许可（IEEE OJVT + arXiv，CC BY 4.0），我们无预印本、仓库无 LICENSE 文件；② 规模大 4 个数量级（50,000 vs 200）——但那是 LLM 生成 JSON 的成本，不是仿真成本，两者不可直接比；③ 已公布 32 个 SOTA LLM 的结果，我们的基线只有一个通用 LLM + tools，这正好又指向第 5 节缺口 1。

**我们比它强的地方**：① 输入是原始 IQ，它整条链路没有信号层；② 真值是带容差判定的数值物理量（频偏 / DOA / 位置 / 逐站 INR），它只有离散标签与单选题；③ 有工具层与信息隔离设计（`public/` 与 `private/`、`abstained` 拒答口径、三视角分层），它是纯问答。

**结论：不是竞争，是上下游。** UAVBench 的场景 JSON 已经假定 `gnss_jam_dbm: -110`、`em_interference: true`、`GPSJamming` 成立——**这些电磁事实它既无法生成、也无法检验**。对外一句话：**"UAVBench 是无人机决策层的基准，我们是电磁感知层的基准；它假定电磁事实存在，我们负责把电磁事实造出来并评测 Agent 能不能解出来。"** 这句话的价值在于：它把我们放进了一个**已发表的坐标系**里，而不是孤立的"另一个数据集"。

### 2.4 形态参照：RF-Agent / ActiveRF-AD

**为什么不入榜**：它是完整的 benchmark——有数据集（`ActiveRF-AD`，synthetic RF scenes）、有动作契约、有判分协议、有公开数字——但**考的不是信号物理量**，所以放在"同层对手"里会误导。

#### 它的任务形态（论文原文要点）

- **动作空间只有两个**：`Acquire(view)`（view = 从视角目录 V 里选的中心频点 + 带宽）或 `Stop`；预算 B = min(B_requested, N)
- **标签是场景级二值**：y(z) ∈ {anomaly, normal}
- **感知层冻结**：Agent 拿到的是探测器输出（判决 / 分数 / 置信度 / 时频框），**拿不到 IQ**。论文原话："We **fix perception across controllers**"
- **隐藏真值比我们更彻底**：场景真值、生成元数据、**未选视角的 IQ 与感知输出**一律不给
- **题干 = 一条自然语言指令**，背后配一份隐藏的"义务" g = (k₊, k₋, f, L, d₋, d₊)，**只给报告器与审计器，Agent 看不到**

#### 它的判分（论文 Eq. 4–6）

```
报告：p ≥ k₊ → anomaly；p = 0 且 n ≥ k₋ → normal；否则 abstain
合规：C(τ; g) = Π c_k            （每条规则违规乘 0）
最终：J = (1/N_ep) Σ C(τ_e; g_e) · R_e     合规 × 答对，乘在一起
```

论文原话："success requires compliance and RF correctness **in the same episode**."

#### 它论文里最看重的成绩不是"检出率"

而是**"答对但不合规"的下降**：joint success 从 65.13% 到 72.12%（+6.99），其中 **6.73 分**来自"RF 答对了但没按指令做"的情况变少。

**它的立意**：同一个观测、同样的剩余资源，**不同指令要求不同动作**——论文原话："following an acquisition timeout with budget and receiver views still available, **a recovery instruction requires another measurement, whereas an abort instruction requires termination**."

#### 对我们的价值（一条，但很实）

它的 **`Acquire(view)` / `Stop` + 预算 + 指令义务**是一套**主动采集契约**。我们的 Agent 是"拿到 4 个文件一次算完"，**没有"我该再采哪一段、什么时候算够了"这一步**。这一条已列入第 5 节借鉴清单。

#### 不构成竞争关系的证据

它的答案里没有频偏、没有 DOA、没有位置、没有体制、没有意图；它的场景是合成的（论文原文："ActiveRF-AD provides **synthetic** RF scenes"）；它的感知层是冻结的，**整条链路里没有原始 IQ 进入 Agent**。

## 3. 十六维对比

维度分四组：**A 题面与答题契约 / B 答案轴与判分 / C 信息隔离与测试集 / D 难度·门槛·可复现·横评**。

> **读表说明**：下表的 RF-Agent 一列**不是同层对手**，而是**形态参照**（见 §2.4）——它在"题面与答题契约""信息隔离"两组上有可对照的设计，但**不考信号物理量**，因此不参与"谁更强"的比较。

### 3.1 A 组：题面与答题契约

| 维度 | 我们 v3 | EMRB | RF-Agent | MERLIN / EM-Bench |
|---|---|---|---|---|
| 题量 | **200 样本 × 1 个八轴任务** | **200 题 × 920 子问** | episode 式（预算 = 采集次数） | **4,200 道 QA**（300 × 14 子任务） |
| 题目颗粒度 | 粗（一题八问一起答） | **细（一题 3–5 个子问）** | 中（一次采集一个判断） | 细（单点 QA） |
| 输入表示 | **4 站 × 8 阵元 × 40000 点原始 IQ**（`public/` 另有 `observations.json`） | 单通道一维复基带（`shape=(32768,)`，L5 65536） | **冻结的感知输出**（不给原始 IQ） | 单通道原始 IQ 1024 点 + 文本 |
| 是否 Agent 式 | ✔ 12 件仪器 + 通用 LLM | ✔ 写 Python 沙箱执行 ≤15 轮 | ✔ 闭环动作 | ✘ 端到端 MLLM |
| 工具层 | **✔ 12 件仪器（能力上限由基准设定）** | ✘ 裸 Python（numpy/scipy/matplotlib） | ✘ 固定视角 | ✘ 无 |
| 输出格式 | 固定 JSON：`{"interferers":[{freq_offset_hz, kind, intent, is_spoof, doa_deg, position_m}]}`，计数由条目数派生 | 结构化答案 + 子问绑定 | 动作序列 + 判断 | 选项 + 自由文本 |
| 观测档 | **同一份 IQ 按 1 / 3 / 4 站取用（S0/S1/S2），不重采** | 无 | 视角选择即观测档 | 无 |
| 拒答语义 | ✔ 空列表 + 无工具候选 = 合法"无干扰"；空列表 + 有候选 = `abstained=true`，并另报 `detection_hit_excl_abstain` | 无显式拒答轴 | 有 `Stop` | 无 |

**读法**：在"输入表示"和"工具层"上我们明显更重（多站多阵元 + 12 件仪器）；但在**题目颗粒度上我们明显更粗**——EMRB 一道题拆 3–5 个子问、一共 920 个计分点，我们 200 个样本各只交一份七元组，等于 200 个计分单元。这直接决定了分数曲线的分辨率。

### 3.2 B 组：答案轴与判分

| 维度 | 我们 v3 | EMRB | RF-Agent | MERLIN |
|---|---|---|---|---|
| 答案轴 | **7 轴**：干扰计数 / 体制·辐射体 / 载频偏移 / DOA / 位置 / 意图 / 欺骗 | 27 题型（频率、时间、功率、信息论） | 异常/正常 + 合规性 | 调制 / 协议 / 雷达参数 / 干扰类 |
| 空间轴 | **✔ DOA(10°) + 位置(50 m) + 逐源逐站 LoS/NLoS** | ✘ | ✘ | ✘ |
| 意图轴 | **✔ 三级 malicious / incidental / benign + `is_spoof`** | ✘ | ✘ | ✘ |
| 同频重叠 | **✔ 同频共道 + 生成期空域可分约束（\|Δu\| ≥ 2/M）** | ~ L4/L5 放 3–5 个发射机共道 | ✘ | ~ 干扰叠加 |
| 判分主体 | **确定性脚本，无 LLM 裁判** | **确定性脚本，无 LLM 裁判** | 确定性 + 轨迹审计器 | 确定性（选项/ROUGE） |
| 容差 | **全局常量**：`FREQ_TOL=0.02`（±40 kHz @4 MHz）、`DOA_TOL_DEG=10`、`POS_GATE_M=50`、体制/意图精确、计数严格 + `within1` 半分 | **按物理量分别定容差**：中心频率 ±0.5 MHz、功率 ±2/±3 dB、SNR ±3 dB、符号率 ±15%、带宽 ±25–30%、PAPR ±2 dB、chirp TBP ±10% | 合规性 | ROUGE/BLEU + 准确率 |
| 匹配方式 | 贪心频偏匹配 + 位置可信 GT 先 40 m NMS；另有 `assoc_answer()` 50 m 贪心配对 | **实体绑定匹配**（答案绑到具体信号与子问） | 轨迹级 | 单点 |
| 前置条件门 | 无 | **✔ L5 prerequisite-gated scoring**（前置不对则下游不计分） | 无 | 无 |

**读法**：这一组里"轴的数量"不构成优势（EMRB 的计分点比我们多得多，前文已声明）。真正的差异是**轴的性质**：

- 我们的 7 轴里有 **4 个（载频偏移 / DOA / 位置 / 意图）在本轮检索到的全部 LLM-Agent 基准里都不存在**——不是因为它们难，而是因为那些基准**只喂单通道一维基带**，空间量在物理上无法提问。
- 反过来我们要承认两件事：① 我们的容差是**三个全局常量**，EMRB 是逐物理量定容差并做前置条件门——**判分精细度我们不如它**；② 我们的匹配有"贪心 + NMS"这类启发式（`match()` 的 40 m NMS 已被 `BENCHMARK_STATUS_2026-10-09.md §7` 列为未解问题，怀疑造成 D1 三站 0.609 反高于四站 0.458），而 EMRB 的实体绑定不吃这种启发式的亏。

## 4. 只看考卷：我们哪里好

按"能不能拿去对外讲"排序，每条都标了口径。

1. **7 个正交答案轴，其中 4 个在全部 LLM-Agent 基准里不存在。**
   口径：*面向原始 IQ 的 LLM/Agent 基准中，载频偏移、DOA、位置、意图这 4 个轴是空白*。不能讲成"整个文献独有"——EMRB 论文自己的对比表把 DeepSense 6G 列为 "Beams or locations"，空间输出在非 LLM 的电磁 ML 里早有先例。

2. **三级意图轴 + 欺骗标志，本轮检索范围内唯一。**
   口径：*没有任何公开基准提供 malicious / incidental / benign 三级意图轴*。最接近的是 WiFiSpectralJam 的**文件级二元** benign/malicious（操作员声明，非逐样本），Jammertest 2025 区分 jamming / spoofing / meaconing 但那是欺骗机制轴、全属恶意；**没有任何基准把微波炉、VFD、焊机这类无意辐射源标成 incidental**，而我们 `emitters.py` 的 `INTENT` 把它们明确归为 incidental（6 类）。

3. **三视角分层 + 预注册门限。**
   口径：*本轮检索范围内没有别的基准做这种分层*。clean（在无干扰样本上跑 19 类分类器，测虚警）/ GT 切片（真值替换考生，测仪器上限）/ tool-view（召回·假簇·条件分类），门限在跑之前写死（0.85 / 0.50 / 0.50）。价值在于：我们的 tool-view 条件分类 **0.438 未过 0.50**，这条 FAIL 只有在分层口径下才说得清——它证明瓶颈在"考生不知道真载频"（受控台上限 0.600），而不是在题目或仪器。

4. **生成期可解性约束（机器可检验，不是战役设计选择）。**
   口径：*本轮检索到的公开干扰/低空数据集与基准里，没有第二家做生成期可解性保证*。我们的三条硬约束：每个干扰源 ≥3 站 LoS 可见、同频源对空域可分 \|Δu\| ≥ 2/M、不合格布点**整样本重抽**（≤6 次）而不是凑数。实测效果：D3/D4「≥3 站可见」17.6%→92.6%、16.1%→96.0%；"报 0 即正确"的样本占比 58%/48% → 30%/6%。这一条同时是**数据质量**和**考卷公平性**。

5. **逐源逐站真值 + 同一份 IQ 按 1/3/4 站取用。**
   口径：*S0/S1/S2 三个观测档共用同一份 IQ，不重采*——同一个物理场景可以在"1 站 / 3 站 / 4 站"三个条件下考同一道题，这让我们能直接测量**站数带来的信息增益**（D1 定位：四站 0.458 vs 三站 0.609 的反常正是这么暴露出来的）。公开数据集里最接近"多接收机 + 空间真值"的是 LoRaIQ（4 站分布式 RRH）与 Twente 分布式多基地 ISAC（8 节点共享时钟、7 条同步链路、100 Hz 动捕），但**都不是基准**，且都没有"逐站逐源 LoS/NLoS + 意图"。

6. **题面与真值的物理隔离 + 零成本重放。**
   口径：*对 EMRB 这一点我们更严*（它同一个 JSON 里同时放题和答案）。同时 `regen_noise.py` 能在冻结信道上纯 numpy 重放接收链、与原管线逐位等价、秒级/样本，配合每样本 30 个 SHA256，**改一处噪声都不用重跑仿真**。

7. **拒答语义有正式定义。**
   口径：空列表 + 工具无候选 = 合法"无干扰"；空列表 + 工具有候选 = 拒答（`abstained=true`），并另报 `detection_hit_excl_abstain`。这一条把"不敢答"和"确实没有"分开，我们检索到的基准里没有同类设计。

- **题目颗粒度粗**：200 样本 × 1 个八轴任务 vs EMRB 200 题 × 920 子问。建议把八轴拆成 8 个独立计分子项（不改数据，只改判分输出），计分点立刻从 200 涨到 1,600。
- **无人类专家基线**：EMRB 也没有，可以并列承认，但如果我们能拿到一位电磁领域研究者的一份答卷，就是一个独占项。
- **难度档 D1 与 D2–D4 不同源**：D1 走 `free_space` 单抽头、D2–D4 走 `sionna_rt` 多径，这既是设计也是变量——对外讲"四档递进"时必须说清递进里包含了**传播后端切换**，否则会被质疑不可比。

## 6. 一页话术

**别人问"你们是不是就是个数据集？"**
> 不是。数据集是被用来训练和测试的原料，基准是拿来考的卷子。我们有题面、有独立答案键、有成文容差、有三个预注册门限，而且我们自己的 Agent 已经在上面考过——D1 检测 0.92、D4 0.36，梯度是我们设计出来的，不是天然存在的。

**别人问"和 EMRB 比呢？"**
> 同一形态，不同科目。EMRB 让 LLM 读单通道一维复基带写代码答物理题，考的是通信信号测量与系统设计；我们让 Agent 拿 12 件仪器去分析 4 站 × 8 阵元的多源干扰态势。EMRB 在题目颗粒度（200 题 920 子问）、判分精细度（逐物理量容差 + 实体绑定 + 前置门）、模型横评（14 个 LLM）和许可证上**都比我们成熟**，这四点我们认。但 EMRB 物理上没有空间维——单通道一维基带，问不出角度和位置，也没有意图轴。

**别人问"和 UAVBench 比呢？"**
> 同域，不同层。UAVBench 问的是"无人机该怎么做"——输入自然语言任务加场景 JSON，答案是七选一；我们问的是"这段电磁环境里有什么"——输入原始 IQ，答案是带容差的频偏 / 方位 / 位置 / 意图。它的 `gnss_jam_dbm`、`em_interference`、`GPSJamming` 是场景 JSON 里的数字和标签，背后没有波形、没有信道、没有接收机：它能测 LLM 知不知道 GPS 干扰会让定位退化，测不了能不能从 IQ 里看出 GNSS 欺骗。所以**不是竞争，是上下游**——它假定电磁事实存在，我们负责把电磁事实造出来并评测 Agent 能不能解出来。它有正式论文（IEEE OJVT）、CC BY 4.0 许可、50,000 的规模、32 个 SOTA LLM 的横评，这四点我们认。
**别人问"和 RF-Agent 比呢？"**
> 不是一回事。RF-Agent 的 `ActiveRF-AD` 考的是**流程合规**——同一个局面、不同指令要求不同动作（该继续采还是必须停），最后报一个场景级二值 `anomaly` / `normal`；而且它的**感知层是冻结的**，Agent 拿到的是探测器输出，**拿不到 IQ**。我们从头到尾考的是**信号物理量**：几个源、什么体制、在哪个频率、哪个方向、什么位置、什么意图。所以它在本文里是**形态参照**，不是同层对手。但它那套「主动采集契约 + 预算 + 指令义务」我们是真的缺，已列进第 5 节的借鉴清单。

**别人问"你们比别人强在哪？"**
> 三件事，都能当场打开仓库验证：**第一**，7 个答案轴里有 4 个（载频偏移 / DOA / 位置 / 意图）在全部面向原始 IQ 的 LLM-Agent 基准里是空白——不是我们做得好，是那些基准的采集几何问不出这些问题；**第二**，每道题在生成时就保证了可解性（每个干扰 ≥3 站可见、同频源空域可分、不合格重抽），实测把"报 0 就得分"的样本从 58% 压到 30%；**第三**，同一个场景能用 1 站 / 3 站 / 4 站三种观测档考，而且不重采数据。

**别人问"你们缺什么？"**（主动说，比被问出来强）
> 四件：没有公开的模型横评（这是我们最该先做的）、没有 held-out 测试集、没有论文、仓库还没放 LICENSE。前两件是工程，后两件是流程。

## 8. 真题实例（原文摘录）

> **取证方式**：`git clone --depth 1 --filter=blob:none --no-checkout https://github.com/mingxuZhang2/EMRB.git` 取文件清单，再 `git show HEAD:data/L1/EMRB_L1_5000.json` 取单题原文。`data/L1..L5/` 下共 200 道题（`.json` 装题干与答案键，`.npy` 装对应 IQ）。本节题面、答案键、评分项**全部为原文摘录，未改写**。

### 8.1 EMRB · L1（Basic Measurement）

`data/L1/EMRB_L1_5000.json`，`archetype: A_bpsk_fm_chirp`（BPSK + FM + Chirp），100 分 / 5 题。

**题面原文（节选）**

```
Signal file: EMRB_L1_5000.npy
Sampling rate: 20 MHz
Number of samples: 32768
Data format: complex64 (numpy)
Recording duration: 1.6384 ms

This frequency band contains 3 non-overlapping independent signal sources
(types include Digital Modulation/Analog FM/Swept Frequency),
distributed as follows based on a preliminary scan:
  - Approx. +3.5 MHz: Digital Modulation signal
  - Approx. -5.8 MHz: Analog FM signal
  - Approx. -9.0~-5.8 MHz: Swept Frequency signal (linear frequency modulation)

Q1 (a) How many distinct independent signals are present in this band? (4 pts)
   (b) Estimate the center frequency (MHz) of each signal, listed from
       lowest to highest. (8 pts)
   (c) Which signal has the strongest power? Which has the weakest? (4 pts)
   (d) What is the power difference in dB between the strongest and
       weakest signals? (4 pts)
Q2 power in dBm -> mW conversion / total power / SNR   (题面直接给出公式 Hint)
Q3 sampling: T = N/fs, Ts = 1/fs, Δf = fs/N, 以及如何把 Δf 减半
Q4 noise floor estimation                              (题面直接给出 -53.0 dBm/20MHz)
Q5 bandwidth category / 3 dB bandwidth / constant-envelope / type id
```

**答案键（`ground_truth`，原文）**

```json
{"signal_count": 3,
 "center_frequencies_MHz": [-7.41, -5.83, 3.46],
 "strongest_signal_MHz": 3.46, "strongest_power_dBm": -29.8,
 "weakest_signal_MHz": -5.83,  "weakest_power_dBm": -33.0,
 "power_difference_dB": 3.2}
```

**评分项（`rubric`，原文）** —— 每题的 `scoring` 均为 `l1-deterministic-v6`

| 评分项 | 分值 | 判据 |
|---|---|---|
| `count` | 4 | exact match |
| `frequencies` | 8 | **±0.5 MHz per signal** |
| `strongest_weakest` | 4 | identify correct signals |
| `power_diff` | 4 | **±2 dB** |
| `bw_category` | 5 | correct category per signal |
| `bw_estimate` | 6 | **±30% per signal** |
| `const_envelope` | 5 | correct identification |
| `type_id` | 4 | correct type per signal |

题面**主动给了粗扫摘要**（源数 + 大致频点）。论文原话解释这一设计的用途：「L1 measures **calibration precision against a known scene rather than detection from scratch**」——L1 不考"发现"，只考"能不能把粗略先验变成可靠数字"。

### 8.2 EMRB · L4（Multi-Signal）

`data/L4/EMRB_L4_1000.json`，`archetype: A_dense_digital`（相邻 PSK/QAM 的密集数字带）。

**题面原文（节选）**

```
Multiple independent signal sources exist within this frequency band
(spectral overlap and burst signals may be present).
Please first analyze the signal environment on your own, then answer:

Q1 -0.3~+2.7 MHz 两个数字调制信号：估符号率与调制阶数，并说明二者如何区分
Q2 +5~+8 MHz 线性调频：时宽带宽积 / 匹配滤波处理增益(dB) / 雷达距离分辨率(m)
Q3 在 -1.46~+0.43 MHz 空隙部署 64QAM (rolloff=0.2)：
   最大连续带宽(MHz) / 最大可达速率(kbps) / 满足 23 dB SNR 所需最小接收功率
Q4 频谱关系最紧张的一对信号：类型、中心频率、占用区间、中心间隔；
   是否重叠及重叠带宽（或保护间隔）；以弱者为目标的功率比(dB)；
   单靠频率选择滤波能否保住目标全带宽 —— 须返回含 13 个字段的单个 JSON
Q5 +1.7 MHz 的 8PSK：占用带内 SNR(dB) / 香农容量上界(Mbps) / 频谱效率距极限多远

Answer format version: emrb-l4-repaired-v1
```

**与 L1 的关键差别**：L4 **撤掉了粗扫摘要**。论文原文：「L2 and L3 open with the same summary, **which is withdrawn from L4 onward**」——L4 起考生必须自己先建信号清单。

**评分项原文（节选）**

Q1 —— `scoring: l4-generic-v3`（20 分）

| 评分项 | 分值 | 判据 |
|---|---|---|
| `symbol_rate_1` | 4 | **±15%**（answer = 350.0 ksps） |
| `mod_order_1` | 4 | **分层给分**：`QPSK` 4 分 / `PSK` 2 分 / `QAM` 2 分 / `digital` 1 分 |
| `symbol_rate_2` | 4 | **±15%**（answer = 150.0 ksps） |
| `mod_order_2` | 4 | 同上（answer = `8PSK`） |
| `reasoning` | 4 | "Whether the analysis method is reasonable (spectral nulls, cyclostationary, etc.)" |

Q4 —— `scoring: l4-deterministic-v1`（20 分）

| 评分项 | 分值 | 容差 |
|---|---|---|
| `pair_and_separation` | 5 | **±0.1 MHz** |
| `spectral_relation` | 5 | **±0.05 MHz** |
| `target_power_ratio` | 4 | **±2 dB** |
| `isolation_geometry` | 6 | **±10%** |

**一道题里四种量、四种容差**：频率对 0.1 MHz、频率关系 0.05 MHz、功率比 2 dB、几何比例 10%。这是第 3.2 节「逐物理量定容差」的实物证据。

### 8.3 与我方真题并排

| | EMRB L1（最易层） | EMRB L4（多信号层） | 我方 D1（最易档） | 我方 D4（最难档） |
|---|---|---|---|---|
| 输入 | 单通道 32768 点 @20 MHz（1.6384 ms） | 同左 | **4 站 × 8 阵元 × 40000 点 @4 MHz（10 ms）** | 同左 |
| 题面给不给先验 | **给了粗扫摘要**（源数 + 大致频点）+ 公式 Hint | **不给**，自己建清单 | 不给（只给站址 / 阵型 / 采样参数） | 不给 |
| 源数 | 3 个，互不重叠 | 多个，**含重叠与突发** | 1 目标 + **0 干扰**（正确答案是空列表） | 1 目标 + **3 干扰** |
| 答案轴 | 计数 / 频点 / 功率 / 噪底 / 体制 / 采样参数 | + 分离 / 共存 / 链路预算 / 香农 | 检测计数 / 体制 / 载频 / DOA / 位置 | **+ 意图 + 欺骗** |
| 容差形态 | 逐评分项（±0.5 MHz / ±2 dB / ±30%） | **逐量纲**（0.1 MHz / 0.05 MHz / 2 dB / 10%） | **3 个全局常量**（±2% 归一化 / 10° / 50 m） | 同左 |
| 空间维 | **无**（单通道） | **无**（单通道） | 4 站 DOA | 4 站 DOA + 位置 |
| 逐源真值粒度 | 逐源参数 | 逐源参数 | 逐源 + **逐站** INR / DOA / 可见性 | 同左 + 干扰事件表 |
| 拒答 | 无此概念 | 无此概念 | `abstained` 单独统计，检测分另报 | 同左 |

### 8.4 这一节说明什么

EMRB 的**判分精细度确实比我们高**——逐量纲容差、分层给分（`PSK` 拿半分）、方法分（`reasoning` 4 分）、L5 的前置条件门。这一点第 3.2 节已承认，本节给出了实物。

但**它的采集几何是单通道**：问不出 DOA、问不出位置、没有逐站可见性，也没有「这里什么都没有」的拒答口径。我们三个容差是全局常量（粗），换来的是**四站空间维 + 七轴 + 200 个逐源真值**。

**一句话**：这不是谁做得更好，是**两把尺子在量不同的东西**——它量「一条链路里的数字算得多准」，我们量「一个空间里的源认得对不对」。
