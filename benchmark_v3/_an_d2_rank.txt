========================================================================================================
D2 逐频窗窄带空间特征值枚举 —— 『源数证据』假设的诊断报告（只读，零 API）
========================================================================================================
假设 H：窄带频窗内 8 元阵空间协方差的超阈特征值个数 ≈『该窗有几个源』，
        从而可替代多站锥交会定位作为源数证据。

【口径自检查】
 1. _band_coherence 实际实现（capture_tools.py:62-77）：先对 FFT 子矩阵按列
    归一化 x /= ||x||_col，再 R = x x^H / n_cols，最后 λ1/Σλ。
    → trace(R) == M == 8；跨阵元不相关的白噪/失配能量各 λ ≈ 1（**不是 1/M**）。
    本脚本沿用同一实现（eigenvalues of R，trace=8），故『λ >> 1 的个数』= 源子空间维数。
 2. 归一化方式：本报告用**比值型**判据 λ_k > ratio × median(λ_{k+1..8})，
    对全局尺度严格不变 → 用 w/median(w) 还是 w/w[-1] 对计数**零影响**；
    JSON 里的 ratio_hist_all / mdl_hist_all 给出原始特征值个数的无条件分布，可核对。
 3. 计数规则：k 从 1 起，且至少保留 2 个特征值当噪声底（否则纯白噪窗
    在 ratio=2 下必然虚报 1 个）——这会**系统性压低**近似秩 7 的场景，
    属于保守口径，对『数源』是有利的选择。
 4. 站↔sX 映射：硬编码 station_a->s0 … station_d->s3，
    并用 truth.json 的 per_station INR 做了逐源自校验（见下方映射校验行）。
    → 映射校验：假设 station_a->s0 … station_d->s3 下，d1_truth.inr_db 与 truth.json 同站同源 INR 的配对相关系数 r = 0.778（n=345）
      绝对偏移 中位 |Δ| = 2.07 dB，均值 Δ = +1.17 dB（两文件噪声口径不同，比值的绝对刻度不可直接互换）
      （r≈0.7 且为 24 个置换里最优 → 映射成立；r≈0 → 映射错。）
      e.g. d2_00000 station_a: 假设 s0 | d1_truth INR=13.39 vs truth.json INR=2.36
      e.g. d2_00000 station_b: 假设 s1 | d1_truth INR=10.06 vs truth.json INR=7.36
      e.g. d2_00000 station_c: 假设 s2 | d1_truth INR=16.49 vs truth.json INR=9.68
      e.g. d2_00000 station_d: 假设 s3 | d1_truth INR=24.31 vs truth.json INR=21.88
    → ref 构造失败 0 次，残差剥离失败 23 次

参数：样本 50 个；窗宽 [10, 20, 50, 100, 200] kHz（步进 = 窗宽，不重叠，覆盖 |f| <= 1.8 MHz = 0.45·fs）；
      阈值倍数 [2.0, 3.0, 5.0]；可见性 INR >= 3.0 dB；功率门控 +3.0 dB（相对全带平均功率）。
      窗中心网格：0, ±w, ±2w ... 直到 |f| > 1.8 MHz（两侧各 180 个，另加 0 频点）。
