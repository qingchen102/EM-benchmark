### A 小节要点
- **所有 A 类条目都是「原语/工具链」或「单一体制」**，没有任何一个是「带语义标签的多体制辐射体库」。

- 具备**显式损伤库 + 种子可复现**的：A22（TorchSig）、A15（Sionna）、A8。
- `gr-siggen`：**❌不存在**。见 D 节。

### B 小节要点
- **微波炉、电焊机**这两个我方类别，**存在 NIST 官方实测复基带数据集**（B1、B3）——这是"公开可回放的真实无意辐射源 IQ"，可直接作为对比参照/验证集。
- **VFD、Corona/PD**：**没有**发现开箱即用的公开 IQ 数据集，只有论文级建模 + 测量方法（B5、B6）。
- **开关电源（SMPS）**：本次**未找到**专门的开源射频发射模型 —— 见 D 节。
- 工业无意辐射的"可引用权威模型"主要是三档：**ITU-R P.372 / SM.2158**（统计背景）、**Middleton Class A / Bernoulli-Gaussian**（脉冲统计）、**CISPR 11 / FCC Part 18**（限值）。

### C 小节要点
- **纯仿真**且管线公开可复现的只有三家：**RadioML（GNU Radio）**、**EMRB（自建 numpy）**、**S-ICDF（Sionna RT）**；加上工具级 **TorchSig**。
- 三家的信道严酷度呈阶梯：**EMRB ≈ 仅带内噪声** < **RadioML ≈ AWGN** < **S-ICDF = 射线追踪多径 + 运动阵列**。
- **没有任何一家是「多站多阵元 + 同频多源共道」**：S-ICDF 有阵列但**只有 1 个同时干扰源**；EMRB 有多信号但**没有空间维度**；RadioML 是单信号。
- **MERLIN 的 EM-100k / EM-134K 生成方式**是本次最大的信息缺口 —— 论文摘要只讲"构建并发布"，未讲生成器；**未确证**，不要替它编造。

## D. 关键否定性结论

### D1. 有没有公开的、开箱即用的「19 类低空电磁辐射体」信号模型库（干扰机 + 工业无意辐射源 + 导航对抗）？
**❌ 没有找到。**

证据（本次逐一核对各类别的实际覆盖面）：
- **RadioML 2016.10a / 2018.01a**：全部是**通信调制识别**类别（无干扰机、无工业无意辐射源、无导航对抗）。出处见 C1。
- **EMRB**：11 类 = `BPSK, QPSK, 8PSK, 16QAM, 64QAM, FM, AM-DSB, OFDM, 2FSK, 4FSK, Chirp`（✅ 逐字取自 README）——**通信调制 + 线性调频**，无干扰机、无工业源、无导航对抗。
- **S-ICDF**：6 类干扰波形 = `Chirp, Modulated, Noise, Multitone, FrequHopper`(+Pulsed)（✅ 逐字取自 HTML 全文）——**只有「干扰机」一族，且只有 1 个同时源**；无工业无意辐射源，无 GNSS 欺骗。
- **TorchSig**：调制/协议 + 通用损伤库，属**通信信号**范畴。
- **GNU Radio / liquid-dsp / MATLAB 工具箱**：是**原语与工具链**，不含任何"辐射体类别字典"。

→ 结论：公开生态里**不存在**一个把「干扰机 + 工业无意辐射源（微波炉/电焊机/变频器/电晕）+ 导航对抗（干扰/欺骗）」收敛进同一套类别定义的信号模型库。我方 19 类中，**只有约 6 类（通信/雷达/GPS 波形）在公开库里有对应物**；`Microwave / Welder / VFD_noise / Corona / GNSS_spoof / GNSS_jam / Chirp_jam / Noise_jam / Tone_jam` 这一组**没有任何公开库以信号模型形式提供**（最多只有 NIST 的**实测数据**或论文级模型，见 B 节）。

### D2. 有没有任何公开信号生成器自带「恶意 / 无意 / 良性」意图标签？
**❌ 没有找到。**

- 已核对的公开生成器（GNU Radio、liquid-dsp、MATLAB 各 Toolbox、Sionna、TorchSig、gps-sdr-sim、RadarSimPy、EMRB、S-ICDF）**全部只在"调制类型 / 协议 / SNR / 损伤参数"维度打标签**，**无一处出现 intent / malicious / benign / unintentional 这类语义轴**。
- 最接近的是**任务级隐含意图**：S-ICDF 通篇做"jamming and spoofing 威胁"，但其数据集标签仍是**波形类别（6 类干扰调制）**，不是意图标签；JamShield / DeepWiFi 的 `jammer` 类也仅是"干扰有无/类别"，未与我方"无意辐射源"同轴分层。
- → 我方的 `intent`（恶意/无意/良性）语义轴，**在公开数据集生态中没有先例可对标**。

### D3. 有没有任何公开仿真管线同时具备：多站多阵元 + 逐源逐站空间真值 + 同频多源共道 + 接收机损伤 + 生成期可解性约束？
**❌ 没有找到。五项同时满足的管线不存在。**

逐项拆解（谁满足了几项）：

| 管线 | 多站/多阵元 | 逐源逐站空间真值 | 同频多源共道 | 接收机损伤 | 生成期可解性约束 | 命中数 |
|---|---|---|---|---|---|---|
| **S-ICDF**（C3） | ✅ 2×2 或 8×1 阵 + 运动轨迹（但**单收**） | ✅ 发射机位置、阵列轨迹/姿态、DoA | ❌ **仅 1 个同时干扰源** | 部分（AWGN，SNR −20…20 dB；无 colored/impulse/correlated 分层） | ❌（OAT 单变量扫描是**可解释性**设计，不是可解性约束） | 2.5 / 5 |
| **EMRB**（C2） | ❌ | ❌ | ⚠️ L4 有多信号共道场景（非空间） | ❌ 仅带内噪声底 | ✅ **强**：题目自带确定性验证器、`±1 dB` 容差、`snr_loss=10log10(duty_cycle)` 可解析推导 | 1.5 / 5 |
| **RadioML**（C1） | ❌ | ❌ | ❌ | ⚠️ AWGN 为主 | ❌ | 0.5 / 5 |
| **TorchSig**（C9） | ❌ | ❌ | ✅ 可合成多信号 | ✅ 损伤库（但非接收机四档噪声分层） | ❌ | 2 / 5 |
| **MIT RF Challenge**（C10） | ❌（单站采集） | 部分（逐源波形） | ✅ 是（同频分离任务） | 真实 | ❌ | 2 / 5 |
| **Sionna 本体**（A15） | ✅ 多天线/MIMO | ✅ 几何真值 | ✅ 可多发射机 | ✅ 可加 | ❌ | 4 / 5（但 Sionna 是**库**，不是现成数据集/管线） |

→ 结论：**没有现成的公开管线**同时满足五项。最接近的"能力载体"是 **Sionna 这个库**（4/5 项能力，缺"生成期可解性约束"），以及 **EMRB 的题目验证器思路**（唯一提供了"生成期可解性约束"的实例，但它没有信道与阵列）。**五要素的联合设计在公开工作中是空白** —— 这正是我方基准的可主张差异点。
