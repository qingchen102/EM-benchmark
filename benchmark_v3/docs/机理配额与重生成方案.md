## 0. 为什么必须显式配额

现行生成器**从不直接抽机理**，机理是两件事的副产物：

1. `gen_dataset.py:291-303 _draw_ifw_freq` 的**重叠度档位**（深/部分/分离 ≈ 各 1/3）→ 深与部分都派生 `co_channel`，只有分离派生 `adjacent`；
2. **池成员资格** → 脉冲家族（`Welder/VFD_noise/Corona`）进池就自动判 `pulse`（D2 池 3/8）。

后果（实测，`benchmark_v3/evidence/axis_baselines.txt`）：

| 档 | 设计上应有的比例 | 实测真值 | 问题 |
|---|---|---|---|
| D2 | 非脉冲源 co:adj = 2:1，叠加脉冲 3/8 ⇒ 期望 co≈42% / pulse≈37% / adj≈21% | **co 49% / pulse 39% / adj 12%** | adj 只有期望的六成 |
| D3 | 恶意池无脉冲，脉冲只来自 50% 混入的 COEX | **co 58% / adj 26% / pulse 16%** | pulse 偏少 |
| D4 | 恶意池 + GNSS_spoof + 50% 混入 | **spoof 40% / co 34% / adj 21% / pulse 5%** | pulse 几乎缺席 |

⇒ **"用档位间接控制机理"不可靠**（还叠加了 QA 拒绝重抽的再抽样偏差）。新方案改为**先定机理、再定参数**，并把配额写成生成后的硬校验。

## 1. 配额总表

**总原则**
- 每档允许的机理**由该档主场景的角色表决定**；档内配额只在该集合内调配（不为了均衡把电焊/GNSS 欺骗塞进物流航线）。
- 配额按**源数**计（不是样本数）——计数轴以"报数完全一致"计分，机理分布按源统计才有意义。
- 允差 ±5 pp（一档 100 源量级下 ±5 源）。

| 档（主场景） | 允许机理（依据 = 场景卡角色表） | 建议配额（按源） | 现行实测 | 理由 |
|---|---|---|---|---|
| **D1 物流航线**（卡 1） | `adjacent`（邻区蜂窝/其他 ISM 频道） | **100%（豁免配额）** | adjacent 27/27 | D1 是**仪器自检与定位基线**档，不是机理考点；保持 100% 可比，D1 数字（det 0.92）继续有效 |
| **D2 居民区共存**（卡 6 池 + 卡 2 舞台） | `co_channel`（WiFi/蓝牙与图传同频，场景主题）<br>`pulse`（微波炉/电焊/变频器/电晕）<br>`adjacent`（窗外蜂窝与其他 ISM 频道） | **co 45% / pulse 30% / adj 25%** | co 49 / pulse 39 / adj 12 | co 是"共存"的主题；pulse 是卡 6 的灵魂但不应压过主体；**adj 必须提上来**（邻道是申报书四类之一，现在统计支撑不足） |
| **D3 城市峡谷**（卡 2） | `co_channel`（压制源落目标带）<br>`adjacent`（压制源落邻道/窗外）<br>`pulse`（混入共存的工业脉冲） | **co 50% / adj 30% / pulse 20%** | co 40 / adj 18 / pulse 11 | 主打"恶意压制 + 多径/邻道"，脉冲是配角（工地/变频器自然存在）；不含 spoof |
| **D4 对抗演习**（卡 9） | `spoof`（GNSS 欺骗，卡 9 招牌）<br>`co_channel` / `adjacent`（压制）<br>`pulse`（工业脉冲） | **spoof 30% / co 30% / adj 20% / pulse 20%** | spoof 50 / co 43 / adj 26 / pulse 6 | 章程 D-1 写的是"全机理齐上"，四类都要有；spoof 现占 40% 挤掉了脉冲，而 D4 开了 `imd3_enabled`+相关噪声，脉冲类更能压出前端非线性 |
| 无 `blocking` | — | 任何档都不出 | — | 链接预算下前端口复合功率 −79 dBm 量级、比 IIP3 低 60+ dB，零正样本（见总表 §2.2）；标了就是伪造 |

**D1 的口径差（只登记，不改）**：规范卡 1 的干扰事件原文是"共存碰撞（同频 ISM 拥挤）"，但生成器为了基线把 D1 频偏**强制分离**（`_draw_ifw_freq` 的 D1 分支，目标半宽 500 k + 保护 `SEP_MARGIN_HZ` 之外）→ 实际全 `adjacent`。这是**有意的设计取舍**（D1 要"看得见"），已写进总表，不改数据。

## 2. 机理 → 池与频偏档的配方表（执行顺序：先定机理）

| 机理 | kind 池 | 频偏 / 带宽档 | 备注 |
|---|---|---|---|
| `co_channel` | D2：`COEX` 非脉冲 5 类（`Bluetooth_FHSS/WiFi_burst/Microwave/Zigbee/DECT`）<br>D3/D4：恶意池优先（`Chirp_jam/Noise_jam/Tone_jam`） | 深重叠（中心 40–200 kHz、bw 400–800 kHz）或部分重叠（中心 200–500 kHz、bw 300–500 kHz） | 抽完必须复核 `band_overlap_hz > 0` |
| `adjacent` | 同 co_channel 的池（D2 可含 `LTE_QPSK` 作"窗外蜂窝"） | 频谱分离档（中心 600–700 kHz、bw 100–200 kHz） | 必须复核 `|f0| ≤ RX_HALF_HZ = ±810 kHz`，否则会派生失败（`mechanism.derive` 直接抛错） |
| `pulse` | `Welder / VFD_noise / Corona` | **任意档**（脉冲判定与频偏正交） | 所以必须先分机理再抽频偏，否则脉冲类会按池份额（3/8）自动膨胀 |
| `spoof` | `GNSS_spoof`（仅 D4） | 不按频偏判定（结构欺骗） | D3 池里没有它 |

**一致性校验**：抽完参数后调用 `benchmark_v3/adapters/mechanism.py:derive()`，返回的机理**必须等于**配额指定的机理；不等则重抽该源（上限 N 次），仍不满足就换该样本重抽。**真值仍是派生的**（不是写死的），配额是设计约束——两者一致才说明落地正确。

## 3. QA 约束 4（提案，接在现有三条之后）

现有三条：① 每个干扰 ≥3 站 LoS 可见；② 同频源 |Δu| ≥ 2/M；③ 不合格布点重抽、不凑数（代码 `gen_dataset.py:325-352`）。

**QA 约束 4（难度平衡，适用范围 D2/D3/D4；D1 豁免）**

- **(a) 机理多样性**：每档真值机理 ≥3 个取值，且最大类占比 ≤50%。
- **(b) 计数轴平衡**：每档"S2 可见源数"≥3 个取值，且最大类占比 ≤50%。
  · 现状：D2 `{1:2, 2:48}`（常数基线 0.96，检测计数轴**没有判别力**）；D3 `{0:2, 1:27, 2:21}`（最大类 54%）；D4 `{2:25, 3:25}`（2 个取值）。
  · 这条是三档共同的**最大结构性缺陷修复**：每档需要覆盖 1/2/3（D4 可到 4）个源的样本，且分布均衡。
- **(c) 意图平衡**：每档三类意图各 ≥20%。
  · 现状：D2 `incidental` 81.6%；D3/D4 `malicious` ≈80% → 意图轴大量分数可用"永远答多数类"拿到。
- **违反处理**：对该样本重抽配额槽位与位置（**不换 seed**），连续 N 次失败则整样本重抽并计数；最终仍不满足就整批报错，不静默放行。

## 4. 生成流程改造（四步）

1. **采样器显式配额**（`gen_dataset.py`）
   - 新增 `plan_mechanisms(difficulty, n_sources, rng) -> list[str]`：按 §1 配额表抽机理序列；
   - 按 §2 配方表把每个机理映射到 `(kind, 频偏/带宽档)`，再走原有布点/功率反推；
   - 保留"重叠度档位"作为**频偏分布的物理设定**（真实 ISM 散布），但它**不再决定机理**；
   - 源数按 QA 4(b) 的分布抽（D2 需要重新允许 1 源与 3 源样本——代码注释记着 3 源曾因 QA 压力被删，这次要靠配额+重抽兜住）。
2. **配额自检**：样本构建完、落盘前调 `mechanism.census()`，对本档累计分布做在线配额校验（滑动窗口），越界即重抽该样本。
3. **候选池筛选**：沿用 2026-10-05 那次的做法——**一个 seed 多生成、按配额筛出 50 个**（`--want 50`），而不是反复换 seed；`--qa-skip` 保留给调试。
4. **只重生成 D2/D3/D4**（各 50）：D1 的采样分支与配额都不变 ⇒ **D1 数据与 0.92 基线保持有效**，省一次生成与一次 API。

## 5. 与现行数据的差异对照

| 维度 | 现行（10-12 之前） | 新方案 |
|---|---|---|
| 机理怎么来 | 重叠度档位 + 池成员资格**间接**产生 | **显式配额**：先定机理 → 再定 kind 与频偏档 |
| D2 机理 | co 49% / pulse 39% / adj 12% | co 45% / pulse 30% / adj 25% |
| D3 机理 | co 58% / adj 26% / pulse 16% | co 50% / adj 30% / pulse 20% |
| D4 机理 | spoof 40% / co 34% / adj 21% / pulse 5% | spoof 30% / co 30% / adj 20% / pulse 20% |
| D2 可见源数 | `{1:2, 2:48}`（常数基线 0.96） | `{1,2,3}` 均衡，最大类 ≤50% |
| D4 可见源数 | `{2:25, 3:25}` | 覆盖 3 个取值（含 4 源样本） |
| 意图分布 | D2 incidental 82%、D3/D4 malicious 80% | 三类各 ≥20% |
| D1 | 全 adjacent，det 0.92 | **不变**（数据与数字都不动） |
| 验收 | QA 三约束 | QA 四约束 + `mechanism.census()` 配额自检 + 旧的可见性/共道分离约束 |
| 规模 | 四档各 50 | **D2/D3/D4 各 50** |

**对分数的影响（预先声明，避免事后误读）**：
- 机理/意图/计数三条轴**都会变难**。计数轴尤其明显：D2 的常数基线 0.96 会被打破，检测准确率大概率从 0.88 掉到 0.5–0.7 区间——**这不是退步，是从"没有判别力"变成"有判别力"**。
- D1 不在重生成范围，0.92 仍与历史可比。

## 6. 代价、风险与止损

| 项 | 估计 |
|---|---|
| 生成耗时 | 含 QA 重抽，D2 单样本约 30–90 s（3 源样本更慢）⇒ 三档候选池 + 筛选约 **1–2 h** 后台一次性跑完 |
| 磁盘 | 三档 ×50 样本，每档约数百 MB–1 GB 级（IQ 2.56 MB/站 × 4 站 + 信道 npz） |
| **必须再放行一次 API 全量** | 新数据 ⇒ 旧答案/成绩单全作废；需要 **D2/D3/D4 各 50 的一次点状重跑**（API 纪律：一次全量已用完，此后只允许点状重跑，故需用户明确放行） |
| 换装纪律 | 生成器改动 ⇒ 新 IQ 必须走完整 RT 生成；跑完做**血统核对**（IQ/观测文件 MD5 与 index 对账）+ 0-path 站审计 + 公开层落盘（`expose_evidence.py --coop`，已接在 `regen_noise.py` 尾部） |
| 止损点 | 若 D2 新数据的仪器侧 gate（clean / GT 切片 / tool-view）明显劣化，**不跑 D3/D4**，先归因再决定 |
| 回退 | 现有 `benchmark_v3/dataset_d{2,3,4}` 先整档备份（沿用 `_pre_noise_20261010` 的做法），随时可切回 |
