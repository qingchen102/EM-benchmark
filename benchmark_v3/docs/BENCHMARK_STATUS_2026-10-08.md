## 1. 这套基准在做什么

四层结构，答"模型能不能把一团电磁噪声讲清楚"：

| 层 | 组件 | 作用 |
|---|---|---|
| 出题 | `gen_dataset.py` + `capture_tools.py` | 合成多站阵列 IQ；同时写两份真值：公开观测 + `capture/private/*_truth.json` |
| 仪器 | `adapters/capture_tools.py` 暴露的工具 | 考生只能调这些工具看数据（角度谱、聚类、解调…） |
| 考生 | `run_capture_agent.py` 驱动 LLM | 10 轮内调工具、最后交一份 JSON 答案 |
| 阅卷 | `eval_dataset.py` | 对 GT 打分，输出 难度 × 观测条件 矩阵 |

**观测条件（S 级）**——这一层决定了哪条评分轴"物理上可观测"：

- **S0 = 单站**（只有 `station_a`）→ 只有**测向 DOA** 能评（单站无法定位）
- **S1 = 3 站**（a+b+c）／ **S2 = 4 站** → 才能评**定位**（50 m 门限）
- 所以"D1 在 S0 下定位 = 0.0"是**正确物理结果，不是退化**（见 §4 的假警报更正）

**主题档**：D1 看得见 / D2 挤得慌 / D3 有人捣乱 / D4 极限藏匿，每档 50 样本。

**读表要点**：

- **难度梯度是真的**：SNR 27 dB → 6.3 dB，遮挡 0% → 74%。D1 到 D3/D4 是量级差异，不是调参。
- **D1 是"干净单站检测题"**：46% 样本完全无干扰，只有 2 种干扰体制。它的价值在于**当仪器出系统错误时能立刻抓住**（09-27 检测 0.96 → 10-08 掉到 0.083 → 修复后回到 1.00，见 §5）。
- **干扰源目录不是编的**：Corona（日冕放电）、Welder（焊接机）、VFD_noise（变频器）是真实工业电磁噪声源，Bluetooth_FHSS/WiFi_burst/DECT/Microwave/Zigbee 是真实民用体制。这一层有工程依据。
- **D3/D4 的"恶意干扰"是考题设定**（扫频/噪声/单音 jam、GNSS 欺骗），是假设的敌方行为模型，**不是统计出来的**。作为仿真题目成立，但要清楚这是"设计"而非"实测"。

## 3. 评分维度：确实多维度

一共 **8 条评分轴 + 3 个观测条件**，且分三个认知层次：

| 层 | 轴 | 口径 |
|---|---|---|
| T1 感知 | 检测 | 该 S 级子集内 INR≥3 dB 视为可检（D3/D4 无空场景，只考数量匹配） |
| T1 感知 | 频偏 | 归一化 \|Δ\|≤0.02 命中率 + MAE |
| T1 感知 | DOA | 仅 S0，\|Δ\|≤10° |
| T1 感知 | 定位 | 仅 S1/S2，50 m 门限 |
| T2 认知 | 体制分类 | D1: tone/noise 体制级；D2–D4: 16 辐射体名 = **溯源** |
| T3 决策 | 敌我意图 | malicious / incidental / benign（贪心匹配） |
| T3 决策 | 欺骗专项 | `is_spoof`，GT 侧 = (kind=="GNSS_spoof")，仅 D4 有正分母 |

**这一层是这套基准最"合格"的部分**：它不是单一准确率排行榜，而是把"看得见 / 认得准 / 找得到 / 判得出敌我"拆开了，还能交叉 S0/S1/S2 看"信息不够时能力怎么退化"。评测口径（`FREQ_TOL=0.02` 等）已注册、不随数据集变——这一点做得对。

**但**：多维度只在"仪器能把源交到考生手上"时才有效。§4 会说明为什么现在还没到那一步。

## 6. 三个结构性问题

### 问题 1：D3 与 D4 是同一批几何（样本量被高估一倍）

实测：

- **目标位置逐样本 50/50 完全相同**
- **目标逐站 SNR 逐样本 50/50 完全相同**
- **seed 序列逐位相同**（`gen_dataset.py:534` `seed = args.seed0 + i`，`--seed0` 默认全档 31000）
- 干扰源同序比对（忽略 GNSS_spoof）**0/50 完全相同**——差异只在频偏/带宽

即：**D3 → D4 是同一条航迹、同一组建筑遮挡，加了第三台发射机（GNSS 欺骗）+ 相关噪声 + IMD3 非线性 + 目标机动多普勒。**
D4 相对 D3 的**真实新增困难确实是落地的**（`correlated_noise_enabled` False→True、`imd3_enabled` False→True、
`velocity_mps` [0,0,0]→[-23.663,-12.765,0]），这一点做得好；**但地理与几何没有重新采样**。
后果：D3 和 D4 不能当两个独立难度档来合并统计，D4 的"50 样本"实际是 D3 那 50 个场景的变体。

### 问题 2：D2 的"挤得慌"没落地

文档/`index.json` envelope 声称 **"2–3 共存辐射体"**，实测 **每样本干扰数 = {1: 2, 2: 48}**——
**三源共道场景一个都没有**。`gen_dataset.py:259` 的注释表明是刻意改成固定 2 个（QA 布点四步），但 envelope 文本没跟着改。
「挤得慌」要考的核心恰好是**多源共道重叠下的可辨识性**，而三源档消失后，这一主题的难度上限被压低了。

### 问题 3：仪器是当前瓶颈，不是模型

D2 gate **tool-view**（把工具真实产出的候选簇交给分类器）：

| 指标 | 实测 | 门限 | 状态 |
|---|---|---|---|
| 召回 recall | **0.561** [55/98] | 0.50 | PASS |
| 假簇率 FAR | **0.623** [91/146] | 0.50 | **FAIL** |
| 条件准确率 cond | **0.473** [26/55] | 0.50 | **FAIL**（差 2.7pp） |
| 端到端 e2e | **0.265** | — | — |
| 可解子集 | 0.591 [55/93] | — | — |

**假簇比真簇还多**（91 vs 55）。含义：**当仪器自己都解不出题，D2 的 agent 分数（0.86/0.41/0.20/0.46）混合了"模型能力"与"仪器缺陷"两种信号，无法归因。**
另外注意 D2 的频偏轴只有 0.20——而 §5 记录 `match()` 修正前后**评测配对用的是频偏**，也就是"最弱的一栏当配对钥匙"。这条口径值得复核。

## 7. 逐条对照"合格 benchmark"的四条标准

| 标准 | 判定 | 依据 |
|---|---|---|
| **能精准测模型能力** | ❌ **目前不能** | ①仪器瓶颈未解（gate 假簇 0.62 > 召回 0.56）②D2/D1 多站数字过期 ③D3/D4 零数据。三条各自独立地阻止了"分数=能力"这个等式 |
| **题目有意义、并非虚构** | ✅ **基本成立（仿真范畴内）** | 物理层是真的：sionna_rt 真实城市建筑 + 多径遮挡、真实波形体制（蓝牙/WiFi/DECT/微波炉/Zigbee/日冕/焊接机/变频器）、真实阵列几何（8 元阵 + 白噪相干度理论值 1/8=0.125 与实测 0.13 吻合）。**不成立的边界**：D3/D4 的"恶意干扰行为"和 GNSS 欺骗是假设的敌方模型，不是实测统计 |
| **题目有价值** | ✅ **成立，且有实证** | 受控 + 有 GT + 可复现 → 能做**能力探测**而非排行榜。最好的证据就是 D1/S0 的 0.083→1.00：这一个案例证明这套基准**确实能抓出"仪器给幻影峰、模型照抄"这种系统性错误**——真实采集里几乎无法归因，仿真里可以 |
| **题目多维度** | ✅ **成立** | 8 条轴（检测/体制/频偏/DOA/定位/意图/欺骗）× 3 个观测条件 × 3 个认知层次，口径已注册。**唯一保留**：多维度要等仪器解得出题才发挥分辨力 |

**综合判定**：**已经是一个"结构合格、当前不可用于给模型打分"的仿真基准。**
结构（题目设计、评分轴、可控性、GT 完备性）是合格的；但**信噪比**——即"分数里有多少是模型能力的信号"——现在不够：
主要噪声来自仪器假簇。修掉仪器瓶颈是唯一能立刻放大基准分辨力的杠杆。
