## 1. 无人机数据链与识别信号

### 1.1 DJI 图传（OcuSync / Lightbridge）与 DroneID

**现状定性**：OcuSync/Lightbridge/O3 为**专有协议，无公开标准文本**。公开资料止步于物理层逆向（OFDM 结构、Zadoff-Chu 序列、Turbo Product Code）与 DroneID 解码；完整视频链路无端到端开源解码器（空白点）。仿真建议：按逆向论文的实测频谱参数（中心频点、带宽、帧周期、跳频图样）做外层建模。

**开源实现**
- **proto17/dji_droneid**（MATLAB/Octave + C++ GNU Radio，MIT）：<https://github.com/proto17/dji_droneid>
  关键参数（实测）：2.4/5.8 GHz（实测 2.3995–2.4595 与 5.7565–5.7965 GHz）；约每 600 ms 一簇突发；带宽约 10 MHz（含保护 15.36 MHz）；9 个 OFDM 符号、QPSK 数据子载波、两段 Zadoff-Chu 参考序列（root 600/147）、TPC 信道编码。测试平台 DJI Mini 2 + Ettus B205-mini。
- **RUB-SysSec/DroneSecurity**（Python，AGPL-3.0）：<https://github.com/RUB-SysSec/DroneSecurity>
  NDSS 2023 论文官方 artifact：OcuSync 2.0 上 Drone-ID 的 PoC 接收机（Zadoff-Chu 同步 → OFDM/QPSK → 解扰 → Turbo → CRC），附 DJI Mini 2 / Mavic Air 2 录制样本。
- **anarkiwi/samples2djidroneid**（Python）：<https://github.com/anarkiwi/samples2djidroneid>，从原始 IQ 解码 DroneID 的独立实现。
- **tmbinc OcuSync 2 逆向笔记**：<https://github.com/tmbinc/random/tree/master/dji/ocusync2>，最早的 OcuSync 2 物理层公开分析之一。
- **alphafox02** 系列（antsdr_dji_droneid / dragonsdr_dji_droneid / droneid-go）：<https://github.com/alphafox02/droneid-go>，Go 实现的 ASTM F3411 接收解码器与实时检测管线。

**论文**
- N. Schiller, M. Chlosta, M. Schloegel et al., "Drone Security and the Mysterious Case of DJI's DroneID," **NDSS 2023**. <https://www.ndss-symposium.org/wp-content/uploads/2023-217-paper.pdf>

### 1.2 开源无人机遥控链路（RC uplink）

- **ExpressLRS**（C/C++ 嵌入式，GPL-3.0）：<https://github.com/ExpressLRS/ExpressLRS>（官网 <https://www.expresslrs.org>）
  全开源 RC 链路：900 MHz 与 2.4 GHz 双频段 LoRa 调制（SX127x/SX1280）+ 跳频，上层以 TBS Crossfire (CRSF) 串口协议承载 RC 数据与遥测；刷新率 25–500 Hz 档位。**是"遥控上行"最完整的开源协议参考**（v3 的 UAV_RC_hopping 为窄带跳频 GFSK，参数可对照 ExpressLRS 的跳频与帧结构）。
- **fishpepper/opensky**（C）：FrSky 协议开源实现，目标硬件 D4R-II/VD5M（2.4 GHz）：<https://github.com/fishpepper/opensky>
- **DIY-Multiprotocol-TX-Module**（C/C++，GPL 系）：<https://github.com/pascallanger/DIY-Multiprotocol-TX-Module>
  协议文档 `Protocols_Details.md` 覆盖 FrSky D16/X2/ACCESS 等数十种 2.4 GHz GFSK 类协议参数。
- **FrSky 遥测帧协议 PDF**（官方）：<https://github.com/jcheger/frsky-arduino/blob/master/FrskyD/doc/FrSky%20-%20Frame%20Protocol%20of%20FrSky%20Telemetry%20Hub%20System%202.0.pdf>

**说明**：FrSky ACCST/ACCESS 为专有协议，开源实现均为逆向/兼容性质；2.4 GHz ACCST 类链路为 GFSK + 跳频（hopping table 由绑定 ID 决定）。

### 1.3 FPV 模拟图传（5.8 GHz）

模拟 FPV **无标准组织文本**，事实标准为：**5 个频段 A/B/E/F/R × 8 信道 = 40 信道**，段内信道间隔约 20 MHz（RaceBand 约 37 MHz 间隔以降低三阶互调），典型频点 5658–5945 MHz；制式为 FM（视频）/AM（音频副载波），带宽约 8–25 MHz。**5.8 GHz 上 FPV/WiFi/反制设备天然同频碰撞**，是同频干扰场景的核心素材。

- Oscar Liang 频率总表（社区权威）：<https://oscarliang.com/fpv-channels>
- QuadMeUp 40 频点明细表：<https://blog.quadmeup.com/2015/11/18/5-8ghz-fpv-channel-frequency-table>
- GetFPV 频率参考图：<https://www.getfpv.com/learn/fpv-essentials/fpv-frequency-reference-chart/>
- itsfpv 交互式信道规划器（模拟 + DJI O3/O4 + HDZero + Walksnail）：<https://itsfpv.de/pages/channel-map>

### 1.6 无人机蜂群机间通信（FANET）

FANET 协议无正式标准文本，事实规范即开源实现中的协议定义；物理层为 LoRa（亚 GHz ISM）。

- **rvt/FANET**（C++17 header-only，LGPL-2.1）：无线电无关的 FANET 协议库（Tracking/Message 报文、多跳转发、ACK、邻居表；仓内 protocol.txt）：<https://github.com/rvt/FANET>
- **gereic/GXAirCom**（C/C++，ESP32+LoRa）：FANET+（FANET + FLARM）协议完整开源实现：<https://github.com/gereic/GXAirCom>
- **lyusupov/SoftRF**（C/C++，GPL-3.0）：多协议航空邻近感知（FANET+、FLARM/OGNTP、P3I，可收 ADS-B 1090ES/978UAT）：<https://github.com/lyusupov/SoftRF>

**说明**：面向消费级无人机蜂群（Wi-Fi Mesh 类）的高质量开源实现未找到。

## 7. 脉冲噪声与环境干扰

### 7.1 微波炉（2.45 GHz）

**关键建模参数**（来自文献）：磁控管 ~2.45 GHz，随市电半周期脉动（约 100/120 Hz 突发），占空比约 50%（变压器式）；频谱呈扫频/啁啾状，功率远高于 802.11。**无专门开源生成器**——按"半周期门控 + 扫频啁啾"自行构造即可。

- A. Kamerman, N. Erkocevic, "Microwave oven interference on wireless LANs operating in the 2.4 GHz ISM band," IEEE PIMRC 1997（多台微波炉频谱实测）：<https://infotooth.tripod.com/documents/Microwave_Oven_Interference_on_Wireless_LANs_Operating_in_the_2.4_GHz_ISM_Band.pdf>
- M. Nassar, X. Lin, B. L. Evans, "Stochastic Modeling of Microwave Oven Interference in WLANs," IEEE ICC 2011（随机建模；逆变器式 vs 变压器式占空比差异）：<https://users.ece.utexas.edu/~bevans/papers/2011/microwave/WiFiInterferenceICC2011Paper.pdf>
- IEEE 802.11-98/240（NTIA 实测汇总）：<https://www.ieee802.org/11/Documents/DocumentArchives/1998_docs/82406S-Effects-of-Microwave-Interference-on-IEEE-802.11-WLAN-Reliability.PDF>
- NIST 实测数据集 "Microwave oven interference measurements at 2.4 GHz"：<https://data.nist.gov/od/id/ark:/88434/mds2-3226>

### 7.2 脉冲噪声模型（Middleton Class A / Bernoulli-Gaussian）

**无权威通用开源实现**（空白点）；Class A 本质为高斯混合（背景高斯 + Poisson(A) 冲击分量，核心参数冲击指数 A 与方差比 Γ），Bernoulli-Gaussian 为逐样本伯努利选通冲击——**自行实现数十行代码比依赖现有仓库更现实**。

- D. Middleton, "Statistical-Physical Models of Electromagnetic Interference," *IEEE Trans. EMC*, EMC-19(3):106–127, 1977（Class A/B/C 奠基论文）。
- M. Ghosh, "Analysis of the Effect of Impulse Noise on Multicarrier and Single Carrier QAM Systems," *IEEE Trans. Comm.*, 44(2):145–147, 1996（Bernoulli-Gaussian 离散模型经典出处）。
- 综述："A Study on Impulse Noise and Its Models"（Middleton/BG/SαS）：<https://ieeexplore.ieee.org/document/8531932>
- 参考代码（小型、面向水声、无许可证）：cebedio/Middleton-Class-A-Underwater-Noise-Generators：<https://github.com/cebedio/Middleton-Class-A-Underwater-Noise-Generators>

## 11. 已知空白点与落地建议

### 11.1 空白点（检索确认无现成开源资源）

| 空白 | 现状 | 对策 |
|---|---|---|
| DTMB **发射端** | gr-dtv 不含 DTMB；dtmb-sdr 仅 RX 且早期 | 按 GB 20600-2006 自行仿真，或以 DVB-T (gr-dtv) 作宽带连续 OFDM 广播源的代理并在 metadata 标注 |
| "gr-jammer" | 不存在（可能已更名/删除） | 用 tiiuae/jamrf 或按 MobiHoc 2005 四类模型自实现 |
| Middleton/BG 脉冲噪声 | 无权威通用实现 | 自实现（高斯混合 + Poisson 选通，数十行） |
| 模拟 FPV | 无标准文本，仅社区频率表 | 按 40 信道频率表 + FM 调制参数建模 |
| 微波炉生成器 | 无开源 | 按 Kamerman/Nassar 参数构造（半周期门控 + 扫频啁啾） |
| OcuSync 视频载荷 | 专有加密，仅物理层逆向 | 以实测频谱参数外层建模（v3 UAV_video_OFDM 现行做法） |
| 对讲机/集群 (DMR/Tetra) | 本轮未检索，未确认专门开源 | 待补检；过渡期可用 GFSK/4FSK TDMA 帧原语近似 |
| 伪基站 | 本轮未检索，未确认专门开源 | 待补检；欺骗类可参考 GNSS spoof + LTE 波形组合 |

### 11.2 许可证注意事项（引用/复用前必读）

- **AGPL-3.0**：srsRAN 4G；**GPL-3.0**：gr-ieee802-11/-15-4、gr-lora_sdr、gr-adsb、gr-radar、gnss-sdr、gr-dect2 ——**只参考协议参数/复现波形，不直接复制代码进基准仓库**（避免传染）；若必须调用，独立进程 + 接口隔离。

### 11.3 落地优先级建议

1. **立刻可对齐 v3 现有原语（参数校准）**：Bluetooth AFH（Core v5.4 §5.1.2）校准跳频行为；DECT（EN 300 175-2）校准 TDMA 帧；微波炉（Nassar 2011）校准占空比/啁啾；GNSS spoof（TEXBAT）校准欺骗参数族；ECM 波形（MobiHoc 四类）校准干扰剧本。
2. **低成本新增辐射体**：Remote ID（opendroneid-core-c 的 C 库 + GB 46750-2025 格式，答案轴天然可出"自报家门/身份核验"题）、ADS-B 突发（gr-adsb + 1090MHz Riddle 教材）、LoRa（LoRaPHY MIT 单文件可移植）、假 ADS-B 注入（OpenScope-sec 9 种攻击直接映射为"欺骗事件表"）。
3. **信道与几何**：NTIA/p528（官方 Python）接入路损基准；TR 36.777 的 300 m AGL 参数与 Cai 2021 (JSAC) 的城市 0–40 m 实测作 Sionna RT 结果的对照锚点；Geo2SigMap/OpenPathNet 提供"任意城市 OSM→RT 场景"管线（v3 现为杭州 LoD1 自建）。
4. **数据集校准**：AERPAW 多高度 LTE IQ、LoRaIQ（含 UAV 标注）、Tampere 无人机暗室录制（2.4/5.8 GHz 高采样率）可作为 v3 仿真输出的真实性抽检对照源。
