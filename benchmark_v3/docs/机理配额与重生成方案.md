# 干扰机理配额表与重生成方案（草案 v1）

> 2026-10-12 立，2026-10-12 晚修订为 v1.1。**状态：用户已拍板（配额照此执行 + 四档各 100 样本），实现已落地、生成进行中**。
> 上游口径见 [`干扰分类总表.md`](干扰分类总表.md)（三轴定义、机理判据、v1–v3 谱系）。

## 0. 为什么必须显式配额

现行生成器**从不直接抽机理**，机理是两件事的副产物：

1. `gen_dataset.py:291-303 _draw_ifw_freq` 的**重叠度档位**（深/部分/分离 ≈ 各 1/3）→ 深与部分都派生 `co_channel`，只有分离派生 `adjacent`；
2. **池成员资格** → 脉冲家族（`Welder/VFD_noise/Corona`）进池就自动判 `pulse`（D2 池 3/8）。

后果（实测，`benchmark_v3/evidence/axis_baselines.txt`）：

| 档 | 设计上应有的比例 | 实测真值 | 问题 |
|---|---|---|---|
| D2 | 非脉冲源 co:adj = 2:1，叠加脉冲 3/8 ⇒ 期望 co≈42% / pulse≈37% / adj≈21% | **co 49% / pulse 39% / adj 12%** | adj 只有期望的六成 |
| D3 | 恶意池无脉冲，脉冲只来自 50% 混入的 COEX | **co 58% / adj 26% / pulse 16%** | pulse 偏少 |
| D4 | 恶意池 + GNSS_spoof + 50% 混入 | **spoof 40% / co 34% / adj 21% / pulse 5%** | pulse 几乎缺席 |

⇒ **"用档位间接控制机理"不可靠**（还叠加了 QA 拒绝重抽的再抽样偏差）。新方案改为**先定机理、再定参数**，并把配额写成生成后的硬校验。

## 1. 配额总表

**总原则**
- 每档允许的机理**由该档主场景的角色表决定**；档内配额只在该集合内调配（不为了均衡把电焊/GNSS 欺骗塞进物流航线）。
- 配额按**源数**计（不是样本数）——计数轴以"报数完全一致"计分，机理分布按源统计才有意义。
- 允差 ±5 pp（一档 100 源量级下 ±5 源）。

| 档（主场景） | 允许机理（依据 = 场景卡角色表） | 建议配额（按源） | 现行实测 | 理由 |
|---|---|---|---|---|
| **D1 物流航线**（卡 1） | `adjacent`（邻区蜂窝/其他 ISM 频道） | **100%（豁免配额）** | adjacent 27/27 | D1 是**仪器自检与定位基线**档，不是机理考点；配额仍豁免，但**本轮同样重生成 100 条**（生成分支与配额不变、adjacent 仍 100%）；n=50 时代的 det 0.92 作为历史记录保留 |
| **D2 居民区共存**（卡 6 池 + 卡 2 舞台） | `co_channel`（WiFi/蓝牙与图传同频，场景主题）<br>`pulse`（微波炉/电焊/变频器/电晕）<br>`adjacent`（窗外蜂窝与其他 ISM 频道） | **co 45% / pulse 30% / adj 25%** | co 49 / pulse 39 / adj 12 | co 是"共存"的主题；pulse 是卡 6 的灵魂但不应压过主体；**adj 必须提上来**（邻道是申报书四类之一，现在统计支撑不足） |
| **D3 城市峡谷**（卡 2） | `co_channel`（压制源落目标带）<br>`adjacent`（压制源落邻道/窗外）<br>`pulse`（混入共存的工业脉冲） | **co 50% / adj 30% / pulse 20%** | co 40 / adj 18 / pulse 11 | 主打"恶意压制 + 多径/邻道"，脉冲是配角（工地/变频器自然存在）；不含 spoof |
| **D4 对抗演习**（卡 9） | `spoof`（GNSS 欺骗，卡 9 招牌）<br>`co_channel` / `adjacent`（压制）<br>`pulse`（工业脉冲） | **spoof 30% / co 30% / adj 20% / pulse 20%** | spoof 50 / co 43 / adj 26 / pulse 6 | 章程 D-1 写的是"全机理齐上"，四类都要有；spoof 现占 40% 挤掉了脉冲，而 D4 开了 `imd3_enabled`+相关噪声，脉冲类更能压出前端非线性 |
| 无 `blocking` | — | 任何档都不出 | — | 链接预算下前端口复合功率 −79 dBm 量级、比 IIP3 低 60+ dB，零正样本（见总表 §2.2）；标了就是伪造 |

**D1 的口径差（只登记，不改）**：规范卡 1 的干扰事件原文是"共存碰撞（同频 ISM 拥挤）"，但生成器为了基线把 D1 频偏**强制分离**（`_draw_ifw_freq` 的 D1 分支，目标半宽 500 k + 保护 `SEP_MARGIN_HZ` 之外）→ 实际全 `adjacent`。这是**有意的设计取舍**（D1 要"看得见"），已写进总表，不改数据。

## 2. 机理 → 池与频偏档的配方表（执行顺序：先定机理）

| 机理 | kind 池 | 频偏 / 带宽档 | 备注 |
|---|---|---|---|
| `co_channel` | D2：`COEX` 非脉冲 5 类（`Bluetooth_FHSS/WiFi_burst/Microwave/Zigbee/DECT`）<br>D3/D4：恶意池优先（`Chirp_jam/Noise_jam/Tone_jam`） | 深重叠（中心 40–200 kHz、bw 400–800 kHz）或部分重叠（中心 200–500 kHz、bw 300–500 kHz） | 抽完必须复核 `band_overlap_hz > 0` |
| `adjacent` | 同 co_channel 的池（D2 可含 `LTE_QPSK` 作"窗外蜂窝"） | 频谱分离档（中心 600–700 kHz、bw 100–200 kHz） | 必须复核 `|f0| ≤ RX_HALF_HZ = ±810 kHz`，否则会派生失败（`mechanism.derive` 直接抛错） |
| `pulse` | `Welder / VFD_noise / Corona` | **任意档**（脉冲判定与频偏正交） | 所以必须先分机理再抽频偏，否则脉冲类会按池份额（3/8）自动膨胀 |
| `spoof` | `GNSS_spoof`（仅 D4） | 不按频偏判定（结构欺骗） | D3 池里没有它 |

**一致性校验**：抽完参数后调用 `benchmark_v3/adapters/mechanism.py:derive()`，返回的机理**必须等于**配额指定的机理；不等则重抽该源（上限 N 次），仍不满足就换该样本重抽。**真值仍是派生的**（不是写死的），配额是设计约束——两者一致才说明落地正确。

## 3. QA 约束 4（已实现，接在现有三条之后）

现有三条：① 每个干扰 ≥3 站 LoS 可见；② 同频源 |Δu| ≥ 2/M；③ 不合格布点重抽、不凑数（代码 `gen_dataset.py:325-352`）。

**QA 约束 4（难度平衡，适用范围 D2/D3/D4；D1 豁免）**

- **(a) 机理多样性**：每档真值机理 ≥3 个取值，且**最大类占比 ≤「计划最大类 + 允差 5 pp」**（D2 门限 50%、D3 55%、D4 35%）。原稿写死 50%，但 D3 的 `co_channel` 目标正好 50%，整数分配舍入到 50.x% 就会误判（2026-10-12 n=6 冒烟实测触发）⇒ 门限与计划允差对齐（`dataset_plan.audit_truths`）。
- **(b) 计数轴平衡**：每档“S2 可见源数”≥3 个取值，且最大类占比 ≤「计划最大类 + 允差 5 pp」（D2/D3/D4 均为 45% + 5 = 50%）。
  · 现状：D2 `{1:2, 2:48}`（常数基线 0.96，检测计数轴**没有判别力**）；D3 `{0:2, 1:27, 2:21}`（最大类 54%）；D4 `{2:25, 3:25}`（2 个取值）。
  · **新方案的源数配额**（已实现）：D2 `{1:35%, 2:45%, 3:20%}`、D3 `{1:30%, 2:45%, 3:25%}`、D4 `{2:35%, 3:45%, 4:20%}`（最大类 ≤45%）。
  · 这条是三档共同的**最大结构性缺陷修复**：把“永远答众数”这条捷径从 0.96 / 0.54 / 0.50 压到 0.45 量级。
- **(c) 意图平衡**：每档覆盖该轴出现的 ≥2 个取值，且最大类占比 ≤75%。
  · 原稿写“三类各 ≥20%”**物理上做不到**：D2 是居民区共存场景，池里没有恶意源，而 `INTENT` 是 kind → intent 的确定性表（`emitters.py:311-332`）⇒ 恶意类在 D2 不存在。
  · 现状：D2 `incidental` 81.6%、D3/D4 `malicious` ≈80%。新方案计划阶段实测预计：**D2 incidental 74% / benign 26%**、**D3 malicious 46% / incidental 39% / benign 15%**、**D4 malicious 60% / incidental 32% / benign 8%**。
  · 意图轴真正“有判别力”要靠“同波形不同意图”的成对设计（登记 §6 待办），本轮只做分布均衡。
- **落地方式（与提案略有出入，已实现）**：不做“逐样本在线重抽”，而是两处硬校验——① **生成时逐源自校**：抽完频偏/带宽后调 `mechanism.derive()`，必须等于计划指定机理，不等即报错重抽该样本（`gen_dataset.py` 的“机理自校失败”）；② **整档跑完普查**：`dataset_plan.audit_truths()` 对盘上真值复算机理并检查 QA4 三项，越界即 `RuntimeError`，**不静默放行**（D1 自动跳过）。

## 3b. QA 约束 5（2026-10-13 拍板，**未实现**）

**动机**：S0 只用 station_a。实测「真值有源、但 station_a 一个都看不到」的样本 —— D2 7/100、D3 14/100、D4 12/100（证据 `benchmark_v3/evidence/_s0_visibility.txt`）。这批样本在 S0 轴上的真值源数是 0，「报 0」既正确又不需要能力，只会把 detection_hit 抬到常数基线之上。

**已做（评测侧，零成本）**：`eval_dataset.sample_counts_for_slevel()` 把这批样本**从该观测档的分母里剔除**，报告单列 `excluded_zero_visible_n` / `n_total_seen`。区分规则是数据驱动的：真值**根本没有源**（D1 的设计干净样本 49/100）→ 计入（报 0 正是要考的）；真值**有源但该子集全不可见** → 不计入。实测：D1×S0 分母仍 50（detection 0.96 不变）、D2×S0 已答 22 里剔 3（0.455→0.500）、D4×S2 不变（0.52）。

**待做（生成侧，下一版）**：
- **(a) 单站可见性**：D2/D3/D4 每个样本必须满足「station_a 至少 1 个可见源」，否则重抽布点（与 QA1 的 ≥3 站可见同源，只把可见性子集换成 S0）。
- **(b) 与 QA4(b) 叠加**：S0 可见源数不得出现 >50% 的单一取值。
- **(c) 验收**：跑完普查 S0 零可见样本数必须为 0 并打印（接在 `dataset_plan.audit_truths()` 之后）。

## 4. 生成流程改造（四步）

1. **计划器（已实现：`benchmark_v3/adapters/dataset_plan.py`）**：按**槽位**排出 `(源数, 机理序列, kind, 频偏档)`——源数与机理配额用最大余额法精确分配；机理用“赤字调度”逐源分配（0.25 抖动保留每样本组合多样性）；kind 从该机理的池里抽，抽完校验意图分布（超 75% 重抽 kind，最多 400 次）。
2. **生成器接线（已实现）**：`gen_dataset.py` 新增 `--plan-seed`（默认 `PLAN_SEED=20261012`）/`--no-plan`（复现旧口径）与 `build_sample(..., plan=...)` 分支；`_draw_ifw_freq` 改为**按计划 tier** 抽频偏（QA 重抽不得改掉机理）；逐源自校见 §3。
3. **候选池筛选**：沿用 2026-10-05 的做法——一个 seed 多生成、`--want 100` 凑满，而不是反复换 seed；`--qa-skip` 让单候选连续 6 次失败时跳过。
4. **范围与规模（用户 2026-10-12 追加：四档各 100 样本）**：D2/D3/D4 用新配额生成 **100** 条；**D1 也重生成 100 条**（分支不变、free_space 秒级），四档为同一代产物。先落暂存目录 `benchmark_v3/_regen_v2/dataset_dX`，零 API 验收通过后再换装（旧数据整档移到 `benchmark_v3/_pre_quota_20261012/`，随时可切回）。

## 5. 与现行数据的差异对照

| 维度 | 现行（10-12 之前） | 新方案 |
|---|---|---|
| 机理怎么来 | 重叠度档位 + 池成员资格**间接**产生 | **显式配额**：先定机理 → 再定 kind 与频偏档 |
| D2 机理 | co 49% / pulse 39% / adj 12% | co 45% / pulse 30% / adj 25% |
| D3 机理 | co 58% / adj 26% / pulse 16% | co 50% / adj 30% / pulse 20% |
| D4 机理 | spoof 40% / co 34% / adj 21% / pulse 5% | spoof 30% / co 30% / adj 20% / pulse 20% |
| D2 可见源数 | `{1:2, 2:48}`（常数基线 0.96） | `{1:35%, 2:45%, 3:20%}`（常数基线 ≤45%） |
| D4 可见源数 | `{2:25, 3:25}` | `{2:35%, 3:45%, 4:20%}`（覆盖 4 源样本） |
| 意图分布 | D2 incidental 82%、D3/D4 malicious 80% | 最大类 ≤75%（计划预计 D2 74%、D3 46%、D4 60%） |
| D1 | 全 adjacent，det 0.92（n=50） | **同代码重生成 100 条**（adjacent 仍 100%；n=50 的 0.92 作历史记录保留） |
| 验收 | QA 三约束 | QA 四约束 + `mechanism.census()` 配额自检 + 旧的可见性/共道分离约束 |
| 规模 | 四档各 50 | **四档各 100**（D2/D3/D4 新配额，D1 同代码重生成） |

**对分数的影响（预先声明，避免事后误读）**：
- 机理/意图/计数三条轴**都会变难**。计数轴尤其明显：D2 的常数基线 0.96 会被打破，检测准确率大概率从 0.88 掉到 0.5–0.7 区间——**这不是退步，是从"没有判别力"变成"有判别力"**。
- D1 本轮**同代码重生成 100 条**（分支与配额不变、无机理计划）；n=50 时代的 0.92 与新一批不可逐样本对比，只能比分布。

## 6. 代价、风险与止损

| 项 | 估计 |
|---|---|
| 生成耗时 | **实测 ≈5 s/样本**（D2/D3/D4 冒烟 6 条各 26–28 s，含 RT 求解）⇒ 四档 100 条 + 候选池重试约 **0.5–1.5 h** 后台一次跑完，比原估（30–90 s/样本）快一个量级 |
| 磁盘 | 四档 ×100 样本；现行四档合计 ≈4.3 GB ⇒ 新的约 8–10 GB；旧档用**移动**（同盘瞬时、不额外占空间） |
| **需要用户放行一次 API** | 新数据 ⇒ 旧答案/成绩单全作废；范围待定：**100/档（成本是 50/档的两倍）还是先 50/档**（API 纪律 `m03195`：一次全量已用完，此后只允许点状重跑，故需明确放行） |
| 换装纪律 | 生成器改动 ⇒ 新 IQ 必须走完整 RT 生成；跑完做**血统核对**（IQ/观测文件 MD5 与 index 对账）+ 0-path 站审计 + 公开层落盘（`expose_evidence.py --coop`，已接在 `regen_noise.py` 尾部） |
| 止损点 | 若 D2 新数据的仪器侧 gate（clean / GT 切片 / tool-view）明显劣化，**不跑 D3/D4**，先归因再决定 |
| 回退 | 现有 `benchmark_v3/dataset_d{1,2,3,4}` 整档移到 `benchmark_v3/_pre_quota_20261012/`（同盘移动=瞬时），随时可切回；`dataset_d2/BASELINE.json` 是 git 跟踪文件，需留在原位或复制回原位 |
