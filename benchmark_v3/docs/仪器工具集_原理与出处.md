# 仪器工具集：原理与出处

> 适用范围：`benchmark_v3`（课题四「低空多源电磁干扰受控仿真基准」）
> 唯一实现出处：`benchmark_v3/adapters/capture_tools.py`（1921 行）
> Agent 侧接线：`benchmark_v3/adapters/run_capture_agent.py`
> 本文所有结论均来自只读源码 + 四档数据集 `_run_log.json` 统计，每个数字都带 `文件:行号` 或统计出处。
> 「出处」列给出算法的经典来源（作者 + 年份 + 载体）；页码未逐条核对，仅作检索线索；凡本仓库实现与经典算法不能一一对应的，一律写「未确证」。

## 1. 一句话总览

`capture_tools.py` 共定义 **37 个函数 + 1 个类**（`grep "^def "` 命中 37 处，`class ToolContext` 1 处）：其中 **12 件是 Agent 可见工具**（`capture_tools.py:1757-1772` 的 `TOOL_FUNCTIONS` 字典，12 个键，运行期由 `run_capture_agent.py:596` 再包一层 `_recording_tools` 记账），**另外 25 个是仪器内部函数**（不在工具表内，Agent 看不到）；四档数据集 8 份 `_run_log.json`、216 个样本的 `round_log` 统计显示 **12 件工具全部被调用过，没有 0 调用的工具**（最少者 `estimate_num_sources_station` 也有 153 次 / 133 个样本）；真正「从没被 Agent 调用过」的是那 25 个内部仪器函数 + `ToolContext` 类，它们只被 `rad_cls/oracle16.py` 的体检 gate 和 `diag/` 探针直接导入调用。

统计口径与出处：`benchmark_v3/dataset_d{1,2,3,4}/*/answers_*/_run_log.json` 共 **8 份**（d1:1、d2:3、d3:3、d4:1，见 §3），每份 `_run_log.json` 是样本数组，各样本 `round_log[*].names` 记录该轮调用的工具名；脚本 `_tmp_toolcall_stats.py`（一次性，已删除）汇总，样本总数 **216**。

## 2. 逐工具表

顺序与 `run_capture_agent.py:143` 的 `SYSTEM_PROMPT_CAPTURE` 工具清单一致（该清单见 `run_capture_agent.py:149-201`）。
通用约定（`capture_tools.py` 模块 docstring，第 1-20 行）：站点为水平 8 元 ULA、半波长间距；测向走**方向余弦 u = sin(az)·cos(el)** 的 1D 空间（`u∈[-0.999, 0.999]`，801 点网格，`capture_tools.py:393-396`），避免 3D MUSIC 的角度脊简并；工具只读 `capture/public/`，不接触 `private/`（`capture_tools.py:17`）。

### 2.9 `analyze_time_frequency_station`

| 项 | 内容 |
|---|---|
| 签名 | `analyze_time_frequency_station(station: str = "station_a", freq_offset_hz: float = 0.0, bandwidth_hz: float | None = None, on_residual: bool = False, **_) -> dict`（`capture_tools.py:1121-1123`） |
| 干什么 | 指定带限切片 + STFT，量时域结构证据：占空比、突发率、跳频信道数、扫频斜率（`capture_tools.py:1124-1129`）。用于区分频谱重叠的共存体（WiFi 突发 / 微波炉间歇 / Zigbee 短包 / DECT 时隙 / 蓝牙跳频） |
| 返回字段 | `station`、`on_residual`、`band_hz`、`duty_cycle`、`burst_count_per_window`、`mean_active_ms`、`frame_power_cv`、`hop_channel_count`、`note`（`capture_tools.py:1163-1186`） |
| 算法/原理 | ① 带限：`mask = (f>=lo)&(f<=hi)` 后 `ifft(...).mean(axis=0)` 降到单通道（`:1140-1143`）；② **STFT**：`win, hop = 64, 32`（`:1147`）、`np.hanning(win)`（`:1149`）；③ 活动检测：`ref = np.percentile(frame_pow, 10)`（`:1153`），`active = frame_pow > ref * 10**(6/10)`（即高于 p10 底 6 dB，`:1154`）；④ `duty = active.mean()`（`:1155`）；⑤ 突发数 = `active` 的 0→1 上升沿计数（`:1156`）；⑥ 变异系数 `cv = std(frame_pow)/mean(frame_pow)`（`:1158`）；⑦ 跳频：逐帧取 FFT argmax 频点（`:1160`），`np.histogram(peaks, bins=64, range=(-2e6, 2e6))`（`:1161`），`hop_ch = #{bin: count > max(5, 0.05·len(peaks))}`（`:1162`） |
| 关键常量 | `win, hop = 64, 32`（`:1147`）；活动门限 **+6 dB over p10**（`:1154`）；直方图 `bins=64, range=(-2e6, 2e6)`（`:1161`）；跳频 bin 门限 `max(5, 0.05*len(peaks))`（`:1162`）；标定指纹（实现前的注释块与 `note` 字段，`:1172` 起）：WiFi/Zigbee 低 duty + 高 CV；微波炉 duty≈0.78 + bursts≈180；DECT duty≈0.6 + CV≈1.3；蓝牙 CV≈0.13 + hop_ch≈12；连续噪声 CV≈0.16 + hop_ch=0 |
| 经典出处 | 短时傅里叶变换：Gabor 1946, *J. IEE*；占空比/突发率/跳频信道数为工程指标，**未确证**单一经典来源 |
| ⚠ 与 Agent 文档不符 | `run_capture_agent.py:179-180` 把本工具描述为 "(u,f) time-frequency ridge map … per-ridge {u, f_lo, f_hi, span, strength}"——那是**内部函数** `_ridge_pool`（`capture_tools.py:428`）的输出格式，本工具根本不返回这些字段。`TOOL_SCHEMAS`（`capture_tools.py:1774` 之后）的描述（duty cycle / burst count / hop-channel count / sweep slope）才与实现一致 |

## 4. 建议弃用 / 合并清单

先行结论：**没有 0 调用工具**，所以下面按「样本覆盖最低 + 信息与别的工具同源 + 职责可内联」三条给出候选。

### 4.1 `estimate_num_sources_station`（153 次 / 133 样本，覆盖 61.6%，覆盖率最低）

- **信息完全同源**：它的 `num_spatial_components` 就是 `_u_scan` 的 `rank`（`capture_tools.py:657`），而 `estimate_doa_station` 已经把同一个 `scan["rank"]` 作为 `mdl_rank` 返回（`capture_tools.py:686`）。两者底层是同一次全带 `_u_scan`（`:656` 与 `:679` 都走 `_u_scan` / `_u_scan_cached`）。
- **额外收益仅一个 clamp**：`rank = min(int(scan["rank"]), int(max_sources) + 1, 8)`（`:657`）与一句 `note`（`:658-665`）。前者可由调用方在 prompt 里说明，后者本就是 prompt 内容。
- **system prompt 提过**：`run_capture_agent.py:152-153`（"- estimate_num_sources_station(station, max_sources): number of spatial components in the full receiver band (MDL rank; …)"）。

### 4.2 `detect_time_domain_station`（161 次 / 157 样本，覆盖 72.7%，覆盖率倒数第二）

### 4.3 `list_radiator_catalog`（195 次 / 195 样本 = 每样本恰好 1 次）

- **它不是仪器，是常量表**：函数体只有 `return {"radiators": RADIATOR_CATALOG, "note": ...}`（`capture_tools.py:911-913`），没有任何测量动作。
