## 1. v2 → v3 变化总览

| 维度 | v2（冻结版） | v3（本层） |
|------|------|------|
| 场景 | 抽象电磁环境（数学信号） | **低空环境**（空地链路 + 真实辐射体） |
| 干扰池 | 5 种真实调制（WiFi/LTE/蓝牙/雷达/GPS 的代表性调制，**连续**波形）+ 简单波形 | **低空辐射体池**（含真实时域行为：跳频/突发包/脉冲串/扩频）|
| 信道 | CFO + 阵列导向 + LNA 饱和 + 阵元失配 + AWGN | + **多径衰落**（空地莱斯/瑞利，各径独立 DOA/时延/多普勒）+ **IQ 不平衡**（逐链路镜像）+ **相位噪声**（公共本振维纳过程）|
| 任务 | 检测/分类/参数估计/DOA/体制识别 | + **辐射体溯源**（display_name 作为答案轴）+ **敌我意图**（恶意/无意/无害）|
| 输出 | .npy (4,1024) + 三 JSON | **完全同构**——v2 的 tools/evaluator 可直接消费 v3 样本 |

| | Zigbee | QPSK 短突发 | 新增 | ✅ |
| 无人机 | UAV_video_OFDM | 连续宽带 OFDM（图传下行） | 私有协议简化 | ✅ |
| | UAV_RC_hopping | 窄带 GFSK 跳频（遥控上行） | 主流为 OFDM 专利，标注待改 | ✅ |

| | **GNSS_jam** | 窄带扫频压制 | **新增（对抗干扰，非正常信号）** | ✅ |
| | **GNSS_spoof** | 合法扩频码、错误频偏/时延 | **新增** | ✅ |
| 城市日用 | **Microwave** | 2.4G 宽带间歇噪 | **新增** | ✅ |
| | **TV_broadcast** | 连续宽带 OFDM | **新增** | ✅ |
| 电子对抗 | **Chirp_jam** | 扫频压制 | **新增** | ✅ |
| | **Noise_jam** | 宽带高斯压制 | **新增** | ✅ |
| | **Tone_jam** | 单音压制 | **新增** | ✅ |

对抗性标记 `is_jamming=True`（GNSS 压制/欺骗、ECM×3）。**敌我意图 `intent` 三级**（v3 新任务轴）：
- `malicious` 恶意：明确破坏性对抗源（GNSS_jam/spoof、Chirp/Noise/Tone_jam）
- `incidental` 无意：非针对本系统的共存/偶发干扰（Microwave、DECT、Zigbee）
- `benign` 无害：正常合法信号，多为背景（通信/广播/导航/图传/雷达/遥控）

意图随 GT 记录（信息隔离：observations 不含），供"敌我区分→优先处置"任务打分。

## 3. 设计原则

1. **复用已验证的信号原语**：新增环境层与时域行为层，基带/信道基础效应/评分接口全部复用已验证实现；
2. **可组合**：信道效应是独立函数，参数暴露为关键词参数，便于消融（"多径贡献多少难度"可以用开关量化）；
3. **信息隔离不变**：辐射体标签仅入 ground_truth/metadata，observations 不含；
4. **每一步过闸**：预注册门槛 + 离线验收流程覆盖每个新效应与新数据集。

---

## 4. 设计依据（与申报书对齐）

申报书对多源干扰智能分析场景的要求：提取**频率偏移、带宽占用、调制方式、空间传播路径**，建立**同频/邻道/阻塞/脉冲**典型干扰特征库 + 电磁指纹库 + 干扰源高精度定位；干扰来源明确含"**同频设备、非法信号源、环境反射**"。v3 的任务轴与辐射体池即按此口径设计：

- 频偏/带宽/DOA → T1 感知任务（v2 已有）；
- 调制/辐射体溯源 → T2 认知任务（v3 新增答案轴）；
- 敌我意图（对应"非法信号源 vs 环境反射"）→ T3 决策任务（v3 新增答案轴）；
- 环境反射/多径 → 信道层（解析多径 + Sionna RT 城市场景）。

已定设计口径：辐射体清单维持 16 种；溯源任务按"体制 → 调制 → 辐射体"细分，敌我意图作为 GT 答案轴；信道参数以申报书定性描述（路径损耗、多径、环境反射）为依据取工程默认，待实测校准；**带宽语义 = 整窗总跨度（OBW99，实测）**，与频谱工具可测口径对齐。

## 5. 物理仿真平台接入

`城市低空电磁信号仿真平台/`（Sionna RT 光线追踪 + 真实慕尼黑建筑几何）已并入本目录，作为可选**信道后端**；16 辐射体池作为**信号源**。

- 适配器 `adapters/cityrf_source.py`：运行时替换平台 `runner.generate` 为 v3 辐射体输出，再调用平台原样 `run_scenario`——信道求解 / 卷积 / 接收 / 导出全复用，不改平台源码；
- 平台信号源已扩展**预设/自由**双模式：预设=16 辐射体（调制与时域结构锁定，功率/频偏/带宽/脉冲可调）；自由=13 种波形（原生 7 种 + v2 基带 gfsk/16qam/64qam/ook/fhss/lfm）任意组合；
- 平台另支持自定义城市地图：`tools/build_city_scene.py` 从 OSM Overpass 下载建筑轮廓生成 LoD1 场景（杭州市中心已内置，见 `priors/hangzhou_geometry/`）；
- **Sionna RT 运行需 WSL + LLVM 后端**（`LD_LIBRARY_PATH=/usr/lib/llvm-17/lib`）；RT 端点必须在室外且天顶可见。

分工：v3 = 考卷 + 答案轴 + 阅卷；物理平台 = 真实空间信道 / 环境。两者互补不替代，真实数据（v4）接入时仅换数据源。

## 6. 分级数据集与评分

评测框架三维：**任务 T1–T3 × 难度 D1–D4 × 观测条件 S0–S2**。

- **任务层**：T1 感知（源数/频偏/带宽/DOA）→ T2 认知（体制/辐射体溯源/干扰类别）→ T3 决策（敌我意图/威胁评估）。
- **难度**（定义为场景包络，SNR 由几何+功率推算、不是旋钮）——四级递进，每一级在上二级上**新增**一组物理困难：

  | 级 | 名字 | 目标侧 | 干扰侧 | 信道 / 观测 | 相对上一级新增的困难 |
  |---|---|---|---|---|---|
  | D1 | 看得见 | 10–20 dBm，视距 | 0/1 个简单干扰（单音/窄带噪声），频率上**与目标分离 ≥50 kHz** | 自由空间+仅热噪声；监测站环绕目标；**采集 4 MHz** | 基线：干扰在频谱空地上、一眼可见 |
  | D2 | 挤得慌 | 10–20 dBm，视距 | 2–3 个**共存辐射体**（蓝牙/WiFi/微波炉/Zigbee/DECT，无害），频率上**互相与目标重叠** | 杭州 RT（真实多径/遮挡）+热噪声；监测站环绕目标；采集 2 MHz | **频谱重叠**：目标宽 + 干扰拥挤成一片，源的分离从"看频谱"退回"需角度/波形分辨" |
  | D3 | 有人捣乱 | **0–10 dBm 低功率 + 放楼后 NLoS**（物理低 SNR） | 1–2 个**恶意压制**（Chirp/Noise/Tone jam）+ 50% 混一个共存源 | 杭州 RT；监测网**固定环绕 AOI**、目标漫游进入 | **目标弱到难测 + 出现恶意意图**：目标 SNR 大幅下降，且干扰从"无害共存"变为"蓄意对抗"（T3 敌我意图成为新答案轴） |
  | D4 | 极限藏匿 | 0–10 dBm + 楼后 + **机动多普勒**（目标带速度） | 含 **GNSS 欺骗**（合法结构、错误参数）+ 恶意压制 + 共存源 | 杭州 RT；接收机开 **IMD3 非线性 + 阵元相关噪声** | **欺骗与非线性**：出现"长得像合法信号"的欺骗源；接收链引入互调产物与相关噪声，干扰源更难分离 |

- **观测条件**：S0 单站 / S1 三站 / S2 四站——同一采集分站评分，得"多站信息增益曲线"。

### 数据集（各 50 条，审计全绿，GT 回放满分）

| 数据集 | 难度 | 传播 | 干扰 | 目标 SNR |
|---|---|---|---|---|
| `dataset_d1/` | D1 | 视距（**采集 4 MHz**） | 50% 无 / 50% 单音或窄带噪声（Hz 域与目标分离 ≥50 kHz） | 12–38 dB |
| `dataset_d2/` | D2 | 杭州 RT | 2–3 共存辐射体 | 15–41 dB |
| `dataset_d3/` | D3 | 杭州 RT + NLoS | 1–2 恶意压制 + 50% 共存 | 1–34 dB |
| `dataset_d4/` | D4 | 杭州 RT + NLoS | GNSS 欺骗 + 恶意压制 + 非线性/相关噪声/多普勒 | 1–34 dB |

要点：设备布点经楼宇占用栅格拒绝采样（真实 OSM 轮廓，不在楼内、离墙≥5 m）；D3/D4 目标置楼后使低 SNR 有物理出处（每站 LoS/NLoS 进 GT）；D2–D4 的干扰-站链路按 RT 实测判定可见性（不可见自动排除出该站答案键）。**D1 采集带宽 2026-09-27 重设计为 4 MHz**：目标 1 MHz（图传物理量）曾占满旧 2 MHz 窗口致干扰无分离空间，正解是开大采集窗口（只动接收端、不动辐射源），干扰约束改 Hz 域显式分离；合作目标先验（型号+名义带宽）印在 `observations.cooperative_sources`，Agent 合法先验以 public 侧为准。

### 工具链（均在 adapters/）

```bash
python gen_dataset.py --difficulty d1..d4 --count 50   # 生成（D2+ 需 WSL .venv-rt）
python audit_dataset.py ../dataset_dX [--d2]           # v1/v2 坑清单审计（应无问题）
python eval_dataset.py ../dataset_dX                   # S0/S1/S2 评分（GT 回放应全 1.0）
python smoke_capture_tools.py ../dataset_dX dX_00000   # 考生侧仪器冒烟（零 token）
```

`audit_dataset.py` 内置已知问题检查：频偏恒 0、频谱/角度分离、全站 INR≥3 可检测性、奈奎斯特防折叠、信息隔离、IQ 有限性。

### 评分口径（T1–T3 全轴）

`eval_dataset.py` 对每个样本输出一份答案 JSON 的评分：检测 / 体制（D1 为 tone/noise 体制级，D2–D4 为 16 辐射体名=溯源）/ 频偏（归一化容差 0.02，即 0.02×fs：D1@4MHz=±80 kHz、D2–D4@2MHz=±40 kHz，跨配置比较需注明）/ DOA（仅 S0，10°）/ 定位（仅 S1/S2，50 m）/ 敌我意图（malicious/incidental/benign，D1 自由模式干扰不进意图分母）/ GNSS 欺骗专项（`is_spoof`，仅 D4 有正分母）。意图 GT = 真值 `intent` 字段，缺省按辐射体名查确定性映射。

### Agent 考生接入（run_capture_agent.py）

复用 v2 运行主循环（10 轮工具对话 + repair），通过模块级替换注入 capture 域 prompt 与站点感知工具（`capture_tools.py`，7 件：频谱/源数/DOA/多站定位/时域/调制特征/辐射体手册）。角度与定位用阵轴方向余弦（u 空间）仪器：水平 ULA 的方向表示存在固有前后瓣镜像对，单站 DOA 只能给出候选对，多站锥面交会按残差消解——这正是 S0→S2 信息增益的物理来源之一。

```bash
python run_capture_agent.py ../dataset_dX --slevel S0 --resume   # 答案写 answers_S0/，跑完自动出矩阵
```
