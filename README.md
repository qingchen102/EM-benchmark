# 低空电磁安全大模型 · 智能干扰分析 Benchmark

> 面向 **「低空安全的类脑推理电磁大模型」**（课题四 · 多源电磁干扰智能分析场景）的
> **可复现、可扩展、可归因**的 Agent 信号分析评测基座。
>
> 以「**出题 → 仪器 → 考生 → 阅卷**」四层解耦的方式，评测大模型 Agent 在低空多源电磁干扰分析上的能力，
> 并为未来正式电磁大模型保留统一的样本格式与评测接口。

---

## 1. 项目要回答的问题

电磁大模型能否**在没有专用物理层编码器**的情况下，仅依靠**信号测量工具 + 自身推理**完成专业的电磁干扰分析？

为此需要一套可控、可评分、可归因的考卷，它必须回答四类问题，并给出精确答案键：

| 问题 | 答案 |
|---|---|
| 有没有干扰、几个源 | 干扰计数 |
| 什么体制 / 什么辐射体 | 19 类低空辐射体标签 |
| 在哪 | 载频偏移 / 来向 / 空间位置 |
| 什么意图 | 恶意 / 无意 / 无害（含 GNSS 欺骗识别） |

**本项目不是电磁大模型本身，而是它的"考场"**：题目（信号模型）可控生成，答案键精确已知，
分数可逐轴归因到题目、仪器或考生。

---

## 2. 方法：四层解耦

| 角色 | 实现 | 说明 |
|---|---|---|
| **信号模型 = 出题** | `benchmark_v3/simulation/` + `benchmark_v3/adapters/gen_dataset.py` | 生成 IQ、场景参数与 Ground Truth，决定题目的真实性与难度 |
| **tools = 仪器** | `benchmark_v3/adapters/capture_tools.py` | 给 Agent 的 12 件测量工具（频谱 / 源数 / 聚类定带 / DOA / 定位 / 波形提取 / 调制特征 / 时频），只返回测量值与候选证据，不下结论 |
| **Agent = 考生** | 通用 LLM + tools（`run_capture_agent.py`） | 自主调用工具、理解测量、综合推理、输出结构化答案 |
| **evaluator = 阅卷** | `benchmark_v3/adapters/eval_dataset.py`、`rad_cls/oracle16.py` | 对照 Ground Truth 按分类 / 数值容差 / 多源匹配评分，并做损失分解 |

### 迭代纪律

每一步改动都按 **预注册门限 → 零成本离线验收 → 小样本在线确认 → 全量基线** 走，
并逐版本封版。这样版本之间可复现、可归因，避免"为了涨分而刷题"。

---

## 3. 关键约定

- **三份 JSON 信息隔离**：内部完整记录、Agent 可见先验（`public/observations.json`）、评测真值
  （`private/`）分离；答案轴只进私有一侧，保证评测公平。
- **答案轴与容差预注册**（写死在 evaluator 里，不随数据集变化）：
  干扰计数（完全一致）、体制/辐射体（精确命中）、载频（归一化 ±0.02 ≈ ±40 kHz）、
  来向（±10°，单站）、位置（50 m 门限，多站）、意图（三级）、欺骗 `is_spoof`（专项）。
- **可检测性 / 可解性约束**：该站 INR ≥ 3 dB 才计入答案键；每个干扰至少 3 站可见；
  同频源对在空域可分。
- **三视角评测**：无干扰样本上的仪器干净度（clean）、用真值替换考生的仪器上限（GT-slice）、
  仪器候选口径（tool-view）必须分开报——否则分数无法归因。

## 4. 版本线

| 版本 | 场景 / 信号模型 | 任务 | 状态 |
|---|---|---|---|
| **V1** | 单天线、4 类简单干扰 | 跑通「Agent 能做信号分类」的完整评估链路 | 历史封版 |
| **V2** | 4 阵元 ULA、多源（1 目标 + 0~2 干扰）、真实辐射体简化调制、物理保真（LNA 饱和 / 阵元失配 / 防折叠 / OBW99 统一） | 检测 / 分类 / 参数估计 / DOA / 体制识别 | 封版（`ds_run19.json`，500 样本） |
| **V3** | **低空环境仿真**：19 类低空辐射体 + 城市射线追踪多径 + 前端噪声按站分档 + 敌我意图 / 辐射体溯源 / 干扰机理答案轴；分级数据集 **D1–D4 × 观测条件 S0–S2**（各 100 样本，配额生成）；公开层（受害者层证据 + 合作链路先验） | V2 全部任务 + 辐射体溯源 + 敌我意图 + **干扰机理** + 分级评测 | **当前版本**，详见 [`benchmark_v3/README.md`](benchmark_v3/README.md) |
| **V4（规划）** | **真实数据**（SDR 采集） | 同 V3 | 规划中 |

**V3 当前成绩（配额数据 D1–D4 各 100 样本，注册口径评前 50；2026-10-12）**

| 档 | 检测计数 | 体制 / 溯源 | 载频 | 空间轴 | 意图 |
|---|---|---|---|---|---|
| D1×S0（单站） | **0.96** | 0.958 | 1.000（10.8 kHz） | DOA 0.625 | —（真值为 legacy tone/noise，不入意图轴） |
| D2×S2（四站） | **0.60** | 0.291 | 0.481（119.6 kHz） | 定位 0.709（195 m） | 0.595 |
| D3×S2（四站） | **0.70** | 0.395 | 0.221（200.2 kHz） | 定位 0.395（584 m） | 0.651 |
| D4×S2（四站） | **0.52** | 0.396 | 0.264（197.2 kHz） | 定位 0.274（653 m） | 0.698 |

**这一代数据把机理与可见源数做成了抽样维度**（2026-10-12 起）：机理配额 D2 co 45% / pulse 30% / adjacent 25%、D3 co 50% / adjacent 30% / pulse 20%、D4 spoof 30% / co 30% / adjacent 20% / pulse 20%；可见源数分布 D2 `{1:35%, 2:45%, 3:20%}`、D3 `{1:30%, 2:45%, 3:25%}`、D4 `{2:35%, 3:45%, 4:20%}`（D1 保持 0/1 源 49/51 平衡）。
换数据后 D2 的 detection 从 0.88 落到 0.60，**这不是能力退步**：旧数据源数 `{1:2, 2:48}` 让「永远答 2」的常数基线高达 0.96，那时的 0.88 其实低于平凡解；新数据基线 0.52，0.60 是首次高于平凡解。

**机理轴（注册臂，只作诊断列）**：D1 0.583 / D2 0.468 / D3 0.593 / D4 0.519，对照**同分母常数基线**
1.000 / 0.456 / 0.477 / 0.340 —— 除 D1（真值只有一类 adjacent，等于无信息）外增益 +0.01~+0.18，仍偏弱。机理是
`kind + 频偏 + 带宽` 的派生量，详见 [`benchmark_v3/docs/干扰机理轴_设计与口径.md`](benchmark_v3/docs/干扰机理轴_设计与口径.md)。

**读表须知**：每条分类轴都要减掉“同分母常数基线”再读 —— 计数轴上 D1 +0.44、D2 +0.08、D3 +0.14、D4 ±0.00
（同分母基线 0.52 / 0.52 / 0.56 / 0.52）；意图轴在 D2 仍低于多数类（0.595 vs 0.734）；**常数基线恒为 0 的载频轴与空间轴**
才是真判别力所在。完整表见 `benchmark_v3/evidence/axis_baselines*.txt` 与
`benchmark_v3/dataset_d2/BASELINE.json` 的 `quota_dataset_2026_10_12` / `axis_baselines_2026_10_12`。

**仪器 gate（同一批数据、零 API）**：clean 四档同为 0.877（PASS）；GT 切片 D2 0.472（FAIL）/ D3 0.551（PASS）/ D4 0.378（FAIL）；
tool-view 召回 D2 0.709 / D3 0.372 / D4 0.206，假簇 0.479 / 0.602 / 0.736 → 三档 tool-view 全 FAIL。
即“仪器在无干扰时不会看花眼、给完美候选时 D3 能答对一半以上”，短板在**把题目变成可判分证据**与**共道带不分流**这两环。
D1 是单站 + legacy tone/noise，走相干门控口径：干净虚警 0/49、有干扰覆盖 0.922、频率命中 0.902。

> V3 的信号模型是"更真实的低空环境仿真"，**不是真实采集**；真实采集属于 V4。
> 为获得真实几何反射与多径，V3 的信道后端可切换到并入的物理仿真平台（Sionna RT）。

## 5. 仓库结构

```text
EM-benchmark/                        # 仓库根
├── benchmark_v1/                    # V1 历史代码（单天线、4 类简单干扰）
├── benchmark_v2/                    # V2（封版）
│   ├── simulation/                  # 信号模型（基带 / 干扰 / 信道 / 样本工厂 / 可视化）
│   ├── tools_v2.py                  # Agent 工具集
│   ├── evaluator_v2.py              # 评估器（存档 / 断点续跑 / 自动重试）
│   └── ds_run19.json                # 500 样本最终基线
├── benchmark_v3/                    # V3 低空环境仿真（当前版本）
│   ├── simulation/                  # 19 类辐射体 + 解析信道
│   ├── adapters/                    # 数据集生成 / 审计 / 评分 / 仪器工具 / Agent 接入 / 平台桥接
│   │   └── rad_cls/                 # 19 类溯源 CNN + 仪器 gate（oracle16.py）
│   ├── 城市低空电磁信号仿真平台/      # 并入的物理级射频仿真工作台（Sionna RT + 城市 LoD1 几何）
│   ├── docs/                        # 场景设计规范 / 全档现状报告 / 开源信号模型资料汇编
│   └── dataset_d{1..4}/             # 四档数据集（各 50 样本；IQ 不入库，BASELINE.json 入库）
└── study/                           # 学习 / 自学材料
```

**两个同处一仓、面向同一场景但承担不同层的系统**：V3 自研信号模型负责「考卷 + 答案轴 + 阅卷」；
物理仿真平台负责「真实的空间信道 / 环境」。二者互补不替代——V4 接入真实数据时只换信号源，
考卷、信息隔离与评测接口全部沿用。

## 6. 快速开始

依赖：`numpy scipy matplotlib pillow openai tqdm`（物理平台另需 `pydantic`；Sionna RT 需 WSL + LLVM）。

```bash
# ── V2（已封版，直接评估）
cd benchmark_v2
python evaluator_v2.py dataset --offline          # 离线验证评分管道（应满分）
python run_bailian_deepseek.py dataset --model deepseek-v3.2 --max-samples 50 --output results.json

# ── V3（当前版本）
cd benchmark_v3
python smoke_test.py                              # 生成样本 + 验证工具链可消费
cd adapters; python -u eval_dataset.py ../dataset_d1    # 离线验证评分管道：GT 回放应全 1.0

# ── V3 数据集：评分与审计
cd adapters
python -u eval_dataset.py ../dataset_d1           # GT 回放（应全 1.0）
python -u eval_dataset.py ../dataset_d2 --answers ../dataset_d2/answers_S2_agent_fix2
python -u audit_dataset.py ../dataset_d3 --d2     # 结构审计

# ── V3 物理平台信道（融合 DEMO，本机 Windows 可直接跑）
cd benchmark_v3
python adapters/cityrf_source.py                  # 多源 + 多接收机（自由空间）
python adapters/cityrf_source.py simple           # 单站回归：1 目标 + 2 干扰
```

各脚本的完整参数、数据集清单、工具集说明与评测口径见 [`benchmark_v3/README.md`](benchmark_v3/README.md)。

## 8. Roadmap

- [ ] **多档基线补全**："难度 × 站数"全矩阵（D1–D4 × S0–S2）跑通，给出多站信息增益曲线。
- [ ] **仪器空间精度**：解决同频共道源在频率上不分流导致的定位误差（当前 211–620 m vs 50 m 门限）。
- [ ] **体制轴瓶颈**：tone/noise 混淆与同频共存体的频谱分离。
- [ ] **干扰机理轴的口径与平衡**：机理目前是 `kind+频偏+带宽` 的派生量（不优于常数多数类），
      需定“题面是否写明派生规则”并平衡 `pulse` 类样本量，否则该轴只能当诊断列。
- [ ] **信道效应消融**：量化多径 / NLoS 对难度的贡献。
- [ ] **前端非线性独立题轴**：近场强信号下的 LNA 压缩 / 互调产物识别（需与几何、软限幅、分类器同步改造）。
- [ ] **更长观测窗**：从 10 ms 扩展到 100 ms–60 s，覆盖跳频统计、开关机剧本与间歇脉冲
      （需生成器时基重写 + 时域工具重标定 + 分段真值）。
- [ ] **V3 → V4**：真实 SDR 采集与四层真值策略（自建已知源 / 合作无人机 / 纯背景标定 / 第三方源弱标注），
      替换仿真信号源，保留考卷、答案轴与阅卷接口。
- [ ] **场景扩展**：场景规范中未落地的 8 张卡（需新的生成器能力）与多载频支持。

## 9. 借鉴与参考

- **MERLIN**（*Building Low-SNR Robust Multimodal LLMs for Electromagnetic Signals*）：借鉴其**评测思想**——
  多任务 / 分层能力评测、按 SNR 分组看鲁棒性、分类与数值估计采用不同评分、区分感知与推理。
  本项目未复现其信号编码器、大规模指令微调与蒸馏训练。
- **S-ICDF 类低空电磁数据集**：作为低空场景建模的参考口径，不作为对比对象。
- **Sionna RT**：物理仿真平台的传播后端，在真实城市几何上解多径与反射。
- **评测方法论**：预注册门限 + 离线验收 + 全量基线的版本化迭代纪律。
