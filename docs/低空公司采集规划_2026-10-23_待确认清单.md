# 低空数据采集 · 待确认清单

**用途**：与杭州低空公司对接前发给对方；答不上来的写"未知"，我们按"默认"列准备。
**版本**：2026-10-23 / v1.0
**回传方式**：直接在表里填，或语音回复编号（如"A1 是 glb，A2 不知道"）。

## 最关心的 5 个问题（如果只有 5 分钟，先答这 5 个）

1. 白模能不能导出三角网格？是什么格式？（A1）
2. 主动发射能不能拿到书面许可？（B1）
3. USRP 是什么型号、几个通道、有没有 TX？（C1）
4. 能进场几天、每天几小时？（D1）
5. 采到的 IQ 能不能带走、能不能公开发表？（A5）
