## 1. v2 → v3 变化总览

| 维度 | v2（当前冻结版） | v3（本草案） |
|------|------|------|
| 场景 | 抽象电磁环境（数学信号） | **低空环境**（空地链路 + 真实辐射体） |
| 干扰池 | 5 种真实调制（WiFi/LTE/蓝牙/雷达/GPS 的代表性调制，**连续**波形）+ 简单波形 | **低空辐射体池**（含真实时域行为：跳频/突发包/脉冲串/扩频） |
| 信道 | CFO + 阵列导向 + LNA 饱和 + 阵元失配 + AWGN | + **多径衰落**（空地莱斯/瑞利，各径独立 DOA/时延/多普勒）+ **IQ 不平衡**（逐链路镜像）+ **相位噪声**（公共本振维纳过程） |
| 任务 | 检测/分类/参数估计/DOA/体制识别 | + **辐射体溯源**（display_name 作为答案轴，V3 方向已记录于 v2 README） |
| 输出 | .npy (4,1024) + 三 JSON | **完全同构**——v2 的 tools_v2/evaluator 可直接消费 v3 样本 |

对抗性标记 `is_jamming=True`（GNSS压制/欺骗、ECM×3）。**敌我意图 `intent` 三级**（v3 新任务轴）：
- `malicious` 恶意：明确破坏性对抗源（GNSS_jam/spoof、Chirp/Noise/Tone_jam）
- `incidental` 无意：非针对本系统的共存/偶发干扰（Microwave、DECT、Zigbee）
- `benign` 无害：正常合法信号，多为背景（通信/广播/导航/图传/雷达/遥控）

意图随 GT 记录（信息隔离：observations 不含），供"敌我区分→优先处置"任务打分。
相对骨架版的缺口回应：GNSS 受扰角色（压制/欺骗）、频谱拥塞中的非无人机信号（微波炉/DECT/Zigbee/广播）、无人机链路、IMD3、敌我意图。

## 3. 设计原则（延续 v2 的方法论）

1. **复用已验证原语**：v3 只新增环境层与时域行为层，基带/信道基础效应/评分接口
   全部复用 v2 代码，不重复造轮子、不引入未验证实现；
2. **可组合**：信道效应是独立函数，参数暴露为关键词参数，便于消融
   （"多径贡献多少难度"可以用开关量化）；
3. **信息隔离不变**：emitter 标签仅入 ground_truth/metadata，observations 不含；
4. **每一步过闸**：v8 的"预注册门槛 + 离线验收"流程延续到 v3 的每个新效应。

## 4. 待师兄确认的问题（定稿前置）

1. **v3 边界**：按"更真实的低空环境仿真"理解是否正确？是否需要/何时引入真实采集数据（S-ICDF 用作建模参考还是对比数据）？
2. **辐射体清单**：上表 16 种是否贴合申报书城市低空场景？是否要补/删（如反制设备、定向攻击、专用集群）？
3. **溯源任务**：辐射体识别是否作为正式计分任务？粗细粒度如何定（体制 → 调制 → 辐射体三级）？**敌我意图（malicious/incidental/benign）已作为 v3 新答案轴落地于 GT，是否单列计分？**
4. **信道参数范围**：多径时延/多普勒/IQ 不平衡/IMD3 参数是否有申报书或实测依据？
5. **带宽语义**：跳频/脉冲类辐射体的 GT 带宽用"瞬时带宽"还是"整窗总跨度"（当前 OBW99 测总跨度，对 FHSS 类偏大）？——影响任务定义与评分。
