## 0. 一句话结论

我们和公开数据集的根本差距**不在"信号更多"**，而在三件事：

| # | 公开数据集普遍的做法 | 我们做的事 |
|---|---|---|
| 1 | 给你一段 IQ，问**一个标量**，或让你**分类** | 给 Agent **12 件仪器 + 任务**，让它交一份**可逐轴判分的分析报告** |
| 2 | 只标「**是什么**」 | 同时标「**是什么 / 在哪 / 什么意图**」，且**逐源、逐站** |
| 3 | **一次性录制**，录完定死 | **种子化可控生成**，题目可重出、可归因、可复盘 |

对外只有这 3 条是**结构性**优势；其余维度多为「量」的差别，讲之前先看 §5。

### 0.1 必须先交代的三个例外：EMRB / RF-Agent / MERLIN

公开文献里已经出现了**三个形态上最接近我们的对手**，都必须先交代：

1. **EMRB**（2026-08，arXiv:2608.24086，投稿 KDD 2027 Datasets & Benchmarks）：也**只给原始 IQ**（`.npy`）、也让 LLM **写 Python 代码、在沙箱里跑、迭代（≤15 轮）**、也用**完全确定性的 verifier**（无 LLM 裁判）判分、也是 **200 道题**，并且 **L4/L5 同样把 3–5 个发射机放进同一次采集**。
2. **RF-Agent / ActiveRF-AD**（2026，arXiv:2610.05485）：真正的**语言 Agent 闭环采集**（`Acquire(view)` / `Stop`），带**独立轨迹审计器**与**联合成功指标**，而且**隐藏真值做得比我们更彻底**（场景真值 / 未选视角 IQ / 任务规格 g 全部不给 Agent）。
3. **MERLIN**（2026，**CVPR 2026**）：代码、数据、基准全部公开，把**单通道原始 IQ 直接送进多模态 LLM**，已有多个 LLM 基线（把 IQ 文本化喂 GPT-5 平均只有 **23.20** 分）。

所以下面这句话**不成立、不能说**：

> ✘ 「我们是唯一的 Agent 式电磁基准。」

真正的差别在**任务域**与**真值结构**，三条：

| # | EMRB 做的 | 我们做的 |
|---|---|---|
| 1 | **通信信号测量与系统设计**（检测 / 功率 / FFT / 符号率 / Eb-N0 / PAPR / ADC 量化 / OFDM 设计），信号是教科书波形（BPSK…64QAM / FM / AM-DSB / OFDM / FSK / Chirp） | **多源干扰态势分析**（几个源 / 什么体制 / 在哪 / 什么意图），辐射体含干扰机与工业脉冲源 |
| 2 | **单通道**采集，无任何空间真值 | **4 站 × 8 阵元**，逐源逐站的 DOA / 位置 / LoS-NLoS |
| 3 | 无意图轴、无仪器层、无可解性约束 | **意图三级 + 欺骗标志**、**12 件仪器可切片**、**生成期可解性约束** |
**一句话对外口径**：*「最接近我们的是 EMRB——同样让 LLM 读原始 IQ 写代码答题；但 EMRB 考的是通信信号测量与系统设计（单通道、无空间轴、无意图轴），我们考的是多站干扰态势分析。」*

**另两句必须会说的**：

- 对 **RF-Agent**：*「它把 Agent 闭环、工具层与隐藏真值都做出来了，但交互对象是**冻结的感知输出**而不是原始 IQ，答案轴只有 anomaly / normal。我们给的是原始物理证据，答案是一份八轴报告。」*
- 对 **MERLIN**：*「它是端到端多模态大模型，无工具层、无代码执行、无空间真值、无意图轴。它是我们要超越的**模型侧基线**，不是同形态的考卷。」*

## 2. 对比维度框架（20 维，分 5 组）

选维度时只保留**能区分"考卷质量"的**，不选"参数量"这类好看但无意义的项。

| 组 | 维度 | 为什么它决定数据集好不好 |
|---|---|---|
| **A 数据本体** | A1 数据来源 · A2 信号表示 · A3 规模 · A4 频段带宽 · A5 类别数 | 决定"能不能用" |
| **B 环境信道** | B1 场景 · B2 信道深度 · B3 接收拓扑 | 决定"真实不真实" |
| **C 难度** | C1 同频多源重叠 · C2 难度分级 · C3 可解性约束 | 决定"难不难、公不公平" |
| **D 答案键** | D1 答案轴数 · D2 空间粒度 · D3 语义轴 | 决定"能不能判分" |
| **E 评测形态** | E1 任务形态 · E2 仪器层 · E3 信息隔离 · E4 可复现溯源 · E5 评测协议 · E6 许可 | 决定"能不能当基准" |

**判据**：一个能评测"电磁大模型会不会做干扰分析"的数据集，必须同时满足 **E1 是 Agent 式答题、D1 有多个正交答案轴、C1 有同频重叠、B3 有多站**。四者缺一，就退化成"分类器训练集"。这是本对比的核心判据。

**读法（表 3.2）**：
- **B2 信道深度**：RadioML 只到 AWGN。我们的 D4 同时开 RT 多径、NLoS、IQ 不平衡、相位噪声、IMD3 非线性、目标多普勒，**并按站独立抽前端噪声配方**。据调研，公开 IQ 数据集里没有做齐这一层的。
- **C3 可解性约束**：这是**最被低估的一列**。公开数据集都是"录了就录了"，我们强制"每个干扰至少 3 站可见、同频源对空域可分，不合格重抽"。效果实测：D3/D4「≥3 站可见」占比 **17.6% → 92.6%**、**16.1% → 96.0%**；"报 0 即正确"的漏洞从 58%/48% 压到 **30%/6%**。**没有这一列，基准会被"什么都不报"刷分。**

**逐项读完的三条结论：**

1. **我们守得住的是 10 项**：仪器层（固定 12 件 vs 自由沙箱 / 冻结感知）、输入表示（多站多阵元 vs 单通道）、采集几何、空间真值、意图轴、辐射体类别含无意辐射源、题目难度与能力层级分离、生成期可解性约束、公开层与真值层隔离、判分容差预注册。
2. **我们必须补的是 4 项**：① **许可**（EMRB 与 MERLIN 都放出了代码与数据，我方仓库连 LICENSE 文件都没有）；② **模型横评**（EMRB 跑了 14 个 LLM、MERLIN 有多个 LLM 基线，我方目前只有自己一个模型）；③ **学术产出**（对手已走通 CVPR / KDD 通道，我方尚未投稿）；④ **方法贡献**（EMRB 有 ReconPilot、RF-Agent 有分层控制器，我方只有基准本身）。
3. **必须当场承认的两条**：① EMRB 的 **L4/L5 同频共存（3–5 个发射机共处一段采集）+ 实体绑定确定性判分**，把我们"多源共道"这条优势压到只剩"**多通道 + 空间真值 + 意图**"三点；② RF-Agent 已经把"**Agent 闭环 + 工具层 + 隐藏真值 + 联合成功指标**"这套评测范式做出来了，**我们的 E3 信息隔离不是独有设计**。

**4. EMRB 实证核查的补充结论（2026-10 复核）**：

- **不是射频、没有真实频段**：它合成的是 **20 MHz 采样率下的复基带**（L1–L4 为 32768 点 / 1.6384 ms，L5 为 65536 点 / 3.2768 ms），载频只是基带内的 MHz 偏移且含负值（L1 [−7.408, +3.455] MHz，L4 [−1.743, +6.500] MHz），**不存在 2.4 GHz 之类真实 RF 频段**。
- **没有仪器层**：全仓库对 `instrument|hardware|probe capab|tool_api|function_calling|available_tools` **零命中**；沙箱是 bubblewrap 隔离的**裸 Python**（numpy/scipy/matplotlib），**能力上限不由基准设定**——与我们固定 12 件仪器、且能切片测仪器上限的做法是两种东西。
- **论文自陈局限（原文，main.tex:582）**：「its scope is also narrower than the name suggests, covering RF communication waveforms and LFM radar sweeps under AWGN rather than the full breadth of electromagnetic phenomena」。
- **三处口径不一致（如实并列，不作推断）**：① 论文写数据总量 **~300 MB**，实测发布物 `data/` 只有 **67.1 MB**（200 个 `.npy` = 62.9 MB），整个 clone 含 `.git` 也仅 71.6 MB；② SNR 一处写 **5 dB–30 dB**（main.tex:642），同一数据手册另一处写 **in-band SNR 18.4–57.9 dB（中位 33.0 dB）**（main.tex:735），未说明是生成目标还是实测；③ 200 题 = **5 seeds × 8 archetypes × 5 levels**。
- **可引用的分布值**（main.tex:729-736）：805 个发射源、每采集 **2–7 个（中位 3）**、占用带宽 11 kHz–5 MHz（中位 540 kHz）、符号率 1–750 ksps（中位 119 ksps）、接收功率 −43.9 至 −22.4 dBm（中位 −32.5 dBm）。

> **⚠ 诚实边界（写稿必须保留）**：EMRB 论文自己的对比表（main.tex:1382-1400）把 **DeepSense 6G** 列为「Beam prediction and sensing tasks → Beams or locations」，即**空间输出在 EM / 无线 ML 领域已经有先例**（属非 LLM 的原始 IQ 推理）。因此严谨表述必须限定为：**「面向原始 IQ 的 LLM 代码推理基准中，EMRB 及其对比的同类基准均无多站多阵元与空间真值」**；不能推成「整个文献独有」。

## 4. 我们到底哪里比他们好（逐条给证据）

按**对外可讲强度**排序：4.1–4.3 是结构性的，4.4–4.6 是工程性的，4.7 是讲"唯一"之前必须知道的措辞安全边界。

### 4.1 把「干扰分析」做成**多轴可判分**的考卷（D1 = 7 个注册轴）

公开数据集问的是"这段 IQ 是什么信号"。我们问的是完整的一串：

> 有没有干扰、几个源 → 什么体制 / 什么辐射体 → 在哪（载频偏移 / 来向 / 空间位置）→ 什么意图（含 GNSS 欺骗识别）

来源：`benchmark_v3/README.md` §1 四问表 + §5.1 答案轴表。
证据：`eval_dataset.py` 实装 7 个注册轴，`FREQ_TOL = 0.02` / `DOA_TOL_DEG = 10.0` / `POS_GATE_M = 50.0` / 意图三级精确 / `is_spoof` 专项。

**措辞注意**：EMRB 的答案轴数量不比我们少（920 子问、实体绑定判分），所以"轴多"本身**不构成唯一性**。我们真正的差异是**轴的内容**：这 7 个轴里有 4 个（载频偏移 / DOA / 位置 / 意图）在本轮全部被查的 LLM-Agent 基准里**都不存在**（见 §4.7）。

### 4.2 用三视角把「题目难」和「考生笨」分开（预注册门限）

我们每一档都同时报三个数：

| 视角 | 含义 | 作用 |
|---|---|---|
| `clean` | 无干扰样本上跑 19 类分类器 | 仪器**会不会看花眼**（虚警） |
| `gt_slice` | 用真值替换考生，只留仪器链路 | **题目上限**（最多能给多少分） |
| `tool_view` | 仪器候选口径（召回 / 假簇 / 条件分类） | 仪器**把题目变成可判分证据**的能力 |

**本轮检索范围内没有别的基准做这种三视角分层。** 有了它，我们才能诚实地说"D2 定位只有 0.679，是因为仪器自身误差中位 211 m，而门限是 50 m，属仪器能力不属题目不可解"——**这句话在其他任何数据集上都讲不出来。**

### 4.3 本轮检索范围内唯一做**生成期可解性约束**的考卷（C3）

三约束：每个干扰 ≥3 站 LoS 可见 / 同频源对 `|Δu| ≥ 2/M` / 不合格布点重抽、不凑数。

实测效果：D3/D4「≥3 站可见」**17.6% → 92.6%**、**16.1% → 96.0%**；"报 0 即正确"的漏洞 **58%/48% → 30%/6%**。

这是**基准可信度的地基**：没有它，"检测计数"这一轴的分数没有意义。

### 4.4 逐源 × 逐站的真值粒度 + 多站同源 IQ

- 同**一份 IQ**，按 S0/S1/S2 分站取用（**不重采**），因此"站数增加带来的信息增益"是可测的、干净的；
- 真值里每个源、每个站都有：`dist_m / doa_deg / pr_dbm / snr_db·inr_db / los_blocked`；
- 公开的无人机 / 干扰数据集几乎全是**单接收机单通道**，做不了"多站信息增益"这类题目。

来源：`d1_truth.json` 的 `per_station` 结构（4 站 × 每源）。

### 4.5 信息隔离（E3）：把"证据"和"答案"物理分开

- Agent 可见：`capture/public/iq_station_{a..d}.npy` + `observations.json`（`receivers` / `tasks` / `cooperative_sources` / `interference_events`）
- 真值：`capture/private/truth.json` + `d1_truth.json`（**所有难度档都叫这个名字**）

`interference_events` 里的 `mechanism ∈ {jam, spoof}` 是意图轴的**行为证据但不是源普查**——给的是部分视图，不是答案。

**注意边界**：这个"给证据不给答案"的分寸**不是我们独有**——`RF-Agent`（arXiv:2610.05485）的隐藏真值做得更彻底（场景真值 / 未选视角 IQ / 任务规格 g 全部隐藏，还配独立轨迹审计器）。我们的真正差别是**给的是原始物理证据（IQ + 观测）而不是冻结的感知输出**。

### 4.6 溯源与可复现（E4）：逐文件哈希 + 源码哈希 + 零成本重放

`run_summary.json` 每样本记录：13 个源码文件 SHA256、17 个产物文件 SHA256、Python/numpy/scipy 版本锁、`noise_patch` 档位与实测噪声底、`backend` 与 `path_count`。

外加：`adapters/regen_noise.py` 在**冻结信道**上重放接收链，纯 numpy、秒级/样本、与原管线**逐位等价**——改噪声档位或采窗长度不必重跑射线追踪。

**这解决了所有仿真数据集最致命的问题：改一个参数就得全量重生成。** 我们不必。

### 4.7 本轮检索确认的三条空白（可作为"唯一性"措辞的安全边界）

对外讲"唯一"之前必须知道边界在哪。本轮对 60 余个数据集做了逐条核查，结论如下：

- **Q1："LLM Agent + 原始**多通道** IQ + 仪器工具集 → 结构化干扰答案（计数 / 体制 / 载频 / DOA / 位置 / 意图）"——没有。** 最接近的两个各缺一半：EMRB（有原始 IQ 与代码沙箱，但**实测为单通道一维复基带**、AWGN only、答案轴无 CFO/DOA/位置/意图，且它唯一的「干扰」题 L4 QT07 只是同频共存的 SIR 与保护间隔几何分析，**不是干扰源识别**）、RF-Agent（有完整 Agent 闭环与隐藏真值，但只吃冻结感知输出、只判 anomaly/normal）。**"多通道 IQ + 测量工具集 + 干扰答案契约"是本轮确认的开放空白。**
- **Q2："意图"（恶意 / 无意 / 良性）标注轴——一个都没有。** 最近似的只是**类别词表**而非意图：MERLIN 的 12 类雷达干扰 + 9 类通信干扰、WASD 的 tone/chirp/pulse 异常类型；RF-Agent 的 anomaly vs normal 是**场景状态**，不是宣示的对抗意图。SpecBench / ORAN-Bench-13K / TelecomGPT / WirelessBench / DeepSense 6G / RadioML / WiSig / ORACLE / HisarMod / ITU 均无意图轴。
- **Q3：把 GNSS 欺骗检测作为计分轴——恰好一家，且不是榜单。** 只有 Tampere 大学那项基于 TEXBAT + OAKBAT 的研究（IEEE Access 2026）把"欺骗检测 + PRN 级分类"做成了计分轴，而且是开放数据研究，不是常设 leaderboard。

**这三条正好对应我方 `D1=7`、`D3 意图轴`、`is_spoof` 三条优势——但它们的正确说法是"本轮公开检索范围内未见"，不是"世上不存在"。**

尤其**空间轴**必须按 §3.5 的诚实边界措辞：EMRB 论文自己的对比表就把 **DeepSense 6G** 列为「Beam prediction and sensing tasks → Beams or locations」，说明**空间输出在 EM / 无线 ML 领域早有先例**（属非 LLM 的原始 IQ 推理）。所以只能讲「**面向原始 IQ 的 LLM 代码推理基准中**，多站多阵元 + 空间真值为空白」，不能推成「整个文献独有」。

1. "**绝大多数**公开数据集问的是**「这段 IQ 是什么信号」**（1 个答案轴；EMRB 是例外，但它的 27 个题型全在**频率 / 时间 / 功率 / 信息论**轴上，**没有角度也没有位置**，唯一涉「干扰」的 L4 QT07 也只是同频共存的 SIR 与保护间隔几何分析，**11 种信号类型里没有任何干扰机波形**——见 §3.5），我们问的是**「有没有干扰、几个、什么体制、在哪、什么意图」**（7 个答案轴，`eval_dataset.py` 实装）。"
2. "我们是**本轮检索范围内唯一**把评测拆成 **clean / GT 切片 / tool-view 三个视角**的干扰分析基准——所以分数**能归因到是题目、仪器还是考生**。"

5. "**Agent 可见层与真值层物理隔离**：事件日志给机制与影响类、不给源普查与计数。（RF-Agent 也做了隐藏真值，但我们的差别是：**给 Agent 的是原始 IQ 而不是冻结的感知输出**。）"
6. "**逐文件 SHA256 + 源码哈希 + 冻结信道零成本重放**，改噪声档位不必重跑射线追踪。"
7. "本轮把无人机 RF、干扰/欺骗/频谱占用、RF/无线 LLM 与 Agent 基准三个方向共 60 余个数据集逐条核查完：**带着三级意图轴（恶意 / 无意 / 良性）的数据集，一个都没有**；**把 GNSS 欺骗检测做成计分轴的，只有 Tampere 一项研究，不是榜单**。"
8. "**「LLM Agent + 原始多通道 IQ + 仪器工具集 → 结构化干扰答案」目前是空白。** 最接近的 EMRB 是单通道、AWGN、无空间轴、无意图轴；RF-Agent 有完整 Agent 闭环但只吃冻结感知输出、只判 anomaly/normal。"
9. "我们和 EMRB 同属「让模型读原始 IQ 自己算」这一代，但**采集几何不同**：它是单通道合成波形、考通信测量与系统设计；我们是 4 站 × 8 阵元、考多源干扰态势。"


### 不能讲（会被一问就破）

- ✘ "我们的数据比真实采集更真实" —— 我们是仿真。
- ✘ "我们的规模最大" —— 比 RFUAV / LoRaIQ / 南极 GNSS 小 1–3 个数量级。
- ✘ "我们的定位精度够用" —— 实测中位 211–620 m vs 门限 50 m。
- ✘ "仪器没有问题" —— tool-view 条件分类 0.438，**唯一一项未过门限**。
- ✘ "所有结果都已就位" —— D3/D4 的部分真值字段（`imd3`/`velocity`/`correlat`）尚未验证是否影响信号。
- ✘ "我们是唯一的 Agent 式电磁基准" —— **EMRB 就是**（LLM 读原始 IQ、写代码、答结构化题），且它已投稿 KDD 2027、跑过 14 个 LLM。
- ✘ "信息隔离是我们的独有设计" —— **RF-Agent 做得更彻底**（场景真值、未选视角 IQ、任务规格 g 全部隐藏），还配了独立轨迹审计器。
- ✘ "多源同频是我们的独有难点" —— **EMRB 的 L4/L5 同样把 3–5 个发射机放进一次采集**，并且用实体绑定判分。我们在这条上的差异只剩**多通道 + 空间真值 + 意图**。
- ✘ "我们的数据集可以直接用" —— **仓库里没有 LICENSE 文件**；而 EMRB 有 MIT + CC BY 4.0、MERLIN 代码数据全公开、RF-Agent 是 arXiv CC BY 4.0。
